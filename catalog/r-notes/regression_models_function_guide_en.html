This guide expands the regressionmodels overview into a model-selection tutorial. Core frequentist examples were executed with R 4.5.2; heavyweight mixed and Bayesian examples follow current official package syntax and are clearly marked optional.

How to use this guide

The regressionmodels overview is a compact lookup table: start with the nature of the response, then identify common fixed-effect, mixed-effect, and brms functions. It deliberately does not claim completeness. This guide turns that table into a workflow, explains what each model assumes, gives runnable examples, and highlights distinctions that a one-page table cannot fully express.

Use Chapters 1–3 to choose a model family, Chapters 4–14 for examples by response type, Chapters 15–17 for mixed and Bayesian extensions, and Chapters 18–20 for diagnostics and a complete function catalog.

A function is not a model assumption. glm() can fit several model families, while glmmTMB() and brm() can fit dozens. Choose the data-generating distribution and dependence structure first; select the function second.

1. The map in one view

The source page organizes models by response support: real-valued, binary, counts, proportions, categories, censored values, compositions, or event times. The second decision is whether observations are independent or grouped/repeated. The third is whether the model should be frequentist or Bayesian.

Response
├─ Continuous
│  ├─ roughly symmetric                  -> lm / lmer
│  ├─ positive and right-skewed          -> Gamma GLM / Tweedie
│  ├─ censored or truncated              -> tobit / censReg / vglm
│  └─ explicitly nonlinear mean          -> nls / nlme / nlmer
├─ Binary or binomial trials             -> glm(binomial) / glmer
├─ Counts
│  ├─ variance near mean                 -> Poisson
│  ├─ overdispersed                      -> negative binomial
│  ├─ structural and sampling zeros      -> zero-inflated
│  └─ zero vs positive process           -> hurdle / truncated count
├─ Proportions
│  ├─ known successes and trials         -> binomial / beta-binomial
│  ├─ continuous in (0,1)                -> beta regression
│  └─ continuous including 0 or 1        -> extended/ordered/inflated beta
├─ Categories
│  ├─ ordered                            -> ordinal cumulative-link model
│  └─ unordered                          -> multinomial model
├─ Composition summing to one            -> Dirichlet regression
└─ Time until event with censoring        -> Cox or parametric survival model

This tree narrows the candidate set; it does not choose covariates, link functions, nonlinear terms, random effects, or causal interpretation.

2. Five questions before writing code

2.1 What values can the response take?

Record its support exactly: all real numbers, positive real numbers, {0,1}, integers 0,1,2,..., an ordered factor, a composition, or a time-plus-event pair. A proportion calculated from 17 successes out of 25 is not the same object as a continuous concentration measured as 0.68.

2.2 What generates zeros and boundaries?

Zero can mean a regular draw from a count distribution, a separate structural state, failure to cross a hurdle, censoring below detection, or an impossible observation. Those mechanisms imply different likelihoods.

2.3 Are observations independent?

Repeated measures, subjects within sites, ratings by judges, and observations within years usually require random effects, generalized estimating equations, cluster-robust uncertainty, or another explicit dependence model. Merely adding a group ID as a fixed numeric predictor does not model within-group correlation.

2.4 Is there an exposure or sampling denominator?

Event counts observed over unequal person-time need an offset. Binomial data need the number of trials. Survey weights need a survey design analysis; quasibinomial() is not a universal substitute for design weights.

2.5 What is the estimand?

Decide whether you need a mean difference, odds ratio, rate ratio, probability difference, category probability, hazard ratio, or full response distribution. Coefficients live on the link scale; most reports also need response-scale predictions.

3. R model formulas and result objects

Most functions follow the same surface grammar:

fit <- modelling_function(
  response ~ main_effect + interaction + transformation,
  data = analysis_data,
  other_model_arguments
)

Useful formula operators:

Syntax Meaning
y ~ x + z Additive fixed effects.
x * z x + z + x:z: both main effects and their interaction.
x:z Interaction only.
I(x^2) Arithmetic protected from formula parsing.
splines::ns(x, 4) A nonlinear spline term.
offset(log(exposure)) A coefficient fixed at 1, common for rates.
(1 | group) Random intercept in mixed-model functions.
(1 + time | subject) Correlated random intercept and random slope.
count_part | zero_part Two-part formula in functions such as zeroinfl().

Model objects support a shared vocabulary, although available methods differ:

summary(fit)
coef(fit)
vcov(fit)
confint(fit)
fitted(fit)
residuals(fit)
predict(fit, newdata = new_data, type = "response")
logLik(fit)
AIC(fit)
model.frame(fit)

Do not assume type = "response" means the same quantity for every class. For a zero-inflated model it may combine model components; for ordinal or multinomial models it may return a probability matrix.

4. Continuous responses: lm() and lmer()

Use a Gaussian linear model when a continuous response is adequately described by a conditional mean with roughly constant, symmetric residual variation.

fit_lm <- lm(mpg ~ wt + hp, data = mtcars)

summary(fit_lm)
confint(fit_lm)
plot(fit_lm)

new_cars <- data.frame(wt = c(2.5, 3.5), hp = c(100, 150))
predict(fit_lm, newdata = new_cars, interval = "prediction")

Interpret wt as an adjusted mean change in mpg per unit of weight, conditional on the formula and its scale. A prediction interval is wider than a confidence interval for the conditional mean because it includes residual variation for a new observation.

Repeated continuous observations

For grouped data, lme4::lmer() adds random effects:

# Optional package: lme4
fit_lmer <- lme4::lmer(
  Reaction ~ Days + (Days | Subject),
  data = lme4::sleepstudy
)

summary(fit_lmer)
lme4::VarCorr(fit_lmer)

This standard example estimates a population-average linear trend plus subject-specific intercept and slope deviations. Random-effects structure should reflect the sampling design and within-group replication, not be selected only by whichever specification converges.

5. Binary outcomes and binomial trials

One binary result per row

fit_logit <- glm(
  am ~ wt + hp,
  family = binomial(link = "logit"),
  data = mtcars
)

coef(fit_logit)                 # log-odds coefficients
exp(coef(fit_logit))            # odds ratios
predict(fit_logit, type = "response")  # fitted probabilities

For a factor response, R models the non-first level as success. Always check levels(response) before interpreting signs.

Successes out of known trials

trial_dat <- data.frame(
  dose = 0:4,
  success = c(2, 5, 11, 17, 19),
  total = rep(20, 5)
)

fit_trials <- glm(
  cbind(success, total - success) ~ dose,
  family = binomial(),
  data = trial_dat
)

predict(fit_trials, type = "response")

The two-column response retains the denominator. Alternatively, a proportion can be supplied with weights = total, but the two-column form is harder to misread.

Quasi-binomial and weights

quasibinomial() estimates a dispersion parameter when grouped binomial variation exceeds the nominal binomial variance:

fit_quasibinomial <- update(fit_trials, family = quasibinomial())
summary(fit_quasibinomial)$dispersion

It is not a full likelihood, so ordinary AIC is unavailable. It also does not automatically handle complex sampling weights or cluster dependence. Use weights = for documented prior weights, and a survey-analysis package when weights arise from a sampling design.

Binary mixed model

# Optional package: lme4
fit_binomial_glmm <- lme4::glmer(
  cbind(incidence, size - incidence) ~ period + (1 | herd),
  family = binomial(),
  data = lme4::cbpp
)

6. Count responses: Poisson, quasi-Poisson, and negative binomial

Poisson regression

fit_poisson <- glm(
  breaks ~ wool * tension,
  family = poisson(link = "log"),
  data = warpbreaks
)

exp(coef(fit_poisson))
predict(fit_poisson, type = "response")

Exponentiated coefficients are multiplicative mean ratios. The Poisson variance equals its mean conditional on predictors; real count data often violate that restriction.

Rates need an offset

rate_fit <- glm(
  events ~ treatment + age + offset(log(person_time)),
  family = poisson(),
  data = cohort
)

The offset converts expected counts to rates while fixing the coefficient of log exposure time at 1. All exposure values must be positive.

Check dispersion

dispersion_ratio <- function(model) {
  rp <- residuals(model, type = "pearson")
  sum(rp^2) / df.residual(model)
}

dispersion_ratio(fit_poisson)

A large ratio is a signal, not a complete diagnosis. Unmodelled heterogeneity, dependence, excess zeros, omitted nonlinearities, and outliers can all produce overdispersion.

Quasi-Poisson or negative binomial?

fit_quasipoisson <- update(fit_poisson, family = quasipoisson())

data("bioChemists", package = "pscl")
fit_nb <- MASS::glm.nb(
  art ~ fem + mar + kid5 + phd + ment,
  data = bioChemists
)

summary(fit_nb)
exp(coef(fit_nb))

Quasi-Poisson changes uncertainty through an estimated dispersion but keeps the same mean structure. Negative binomial specifies a full count distribution with an estimated shape/dispersion parameter, allowing likelihood-based AIC and prediction intervals. Neither automatically solves zero inflation or clustering.

7. Excess zeros, hurdle models, and zero truncation

Zero-inflated versus hurdle

Model Zero mechanism Positive counts
Zero-inflated A structural-zero process plus zeros still possible from the count distribution. Ordinary Poisson or negative-binomial count component.
Hurdle A binary process determines zero versus positive. A zero-truncated count distribution conditional on crossing the hurdle.
Zero-truncated Zeros cannot enter the sample by design. One positive-count distribution; no zero process is fitted.

Choose from the data-generating story. A histogram with many zeros is not sufficient evidence that two processes exist.

pscl examples

fit_zip <- pscl::zeroinfl(
  art ~ fem + mar + kid5 + phd + ment | fem + mar,
  data = bioChemists,
  dist = "poisson"
)

fit_hurdle <- pscl::hurdle(
  art ~ fem + mar + kid5 + phd + ment | fem + mar,
  data = bioChemists,
  dist = "negbin",
  zero.dist = "binomial"
)

summary(fit_zip)
coef(fit_zip, model = "count")
coef(fit_zip, model = "zero")

The formula before | controls the count mean; the formula after | controls the extra-zero or hurdle process. Using y ~ x without | reuses the same predictors in both components.

Mixed and flexible count models with glmmTMB

# Optional package: glmmTMB
data("Salamanders", package = "glmmTMB")

fit_zinb_mixed <- glmmTMB::glmmTMB(
  count ~ mined + (1 | site),
  ziformula = ~ mined,
  family = glmmTMB::nbinom2(),
  data = Salamanders
)

fit_hurdle_mixed <- glmmTMB::glmmTMB(
  count ~ mined + (1 | site),
  ziformula = ~ mined,
  family = glmmTMB::truncated_nbinom2(),
  data = Salamanders
)

The second model combines a structural-zero component with a positive truncated negative-binomial component, which gives a hurdle interpretation.

8. Proportions and ratios

The most important distinction is whether the numerator and denominator are observed counts.

Response Appropriate starting point
17 successes out of 25 Binomial with cbind(17, 8); beta-binomial if extra-binomial variation is modelled.
Continuous measurement 0.63 in (0,1) Beta regression.
Continuous measurement including exact 0/1 Extended-support, ordered, or zero/one-inflated beta depending mechanism.
Several positive shares summing to one Dirichlet or another compositional model.

Classical and variable-precision beta regression

data("ReadingSkills", package = "betareg")

fit_beta <- betareg::betareg(
  accuracy ~ dyslexia * iq | dyslexia + iq,
  data = ReadingSkills
)

summary(fit_beta)
predict(fit_beta, type = "response")

The first formula models the mean; the part after | models precision. A larger precision means less conditional variation around the mean.

Current betareg can handle boundaries

The source overview advises special models for exact 0 and 1. That remains a useful conceptual warning, but current betareg() has added extended-support beta regression and automatically selects it when boundary observations are present:

fit_extended_beta <- betareg::betareg(
  accuracy1 ~ dyslexia * iq | dyslexia + iq,
  data = ReadingSkills
)

summary(fit_extended_beta)

This treats boundaries as censored exceedances of a single extended beta process. If 0 and 1 arise from separate qualitative states, use a zero/one-inflated beta model instead. glmmTMB::ordbeta() is another one-process model for closed-interval responses.

Beta-binomial for count proportions

# successes and failures must be integer counts
fit_betabinomial <- VGAM::vglm(
  cbind(success, total - success) ~ dose,
  family = VGAM::extbetabinomial(),
  data = trial_dat
)

Beta-binomial is not a replacement for continuous beta regression. It models extra variation in binomial trials with known denominators.

9. Ordered and unordered categorical responses

Ordinal response

Likert categories such as low < medium < high contain order but not known equal spacing. Cumulative-link models estimate category thresholds and a shared predictor effect under the proportional-odds version.

data("housing", package = "MASS")

fit_polr <- MASS::polr(
  Sat ~ Infl + Type + Cont,
  weights = Freq,
  data = housing,
  Hess = TRUE
)

summary(fit_polr)

The ordinal package provides a broader interface and diagnostic tests:

data("wine", package = "ordinal")

fit_clm <- ordinal::clm(
  rating ~ temp + contact,
  data = wine,
  link = "logit"
)

ordinal::nominal_test(fit_clm)
ordinal::scale_test(fit_clm)

For repeated ratings by judges:

fit_clmm <- ordinal::clmm(
  rating ~ temp + contact + (1 | judge),
  data = wine,
  Hess = TRUE,
  nAGQ = 5
)

brglm2::bracl() fits adjacent-category ordinal models and is useful when the cumulative/proportional-odds formulation is not the desired process.

Multinomial response without natural order

fit_multinom <- nnet::multinom(
  Species ~ Sepal.Length + Sepal.Width,
  data = iris,
  trace = FALSE,
  Hess = TRUE
)

predict(fit_multinom, type = "probs")
predict(fit_multinom, type = "class")

The first outcome level is the baseline. Scale numeric predictors reasonably; the official documentation warns that poorly scaled predictors can slow or prevent convergence. brglm2::brmultinom() provides bias-reduced multinomial fitting.

10. Positive, skewed, and semicontinuous responses

Gamma GLM

Gamma regression is a common model for strictly positive, right-skewed responses where variance increases with the mean.

fit_gamma <- glm(
  mpg ~ wt + hp,
  family = Gamma(link = "log"),
  data = mtcars
)

exp(coef(fit_gamma))
predict(fit_gamma, type = "response")

The dataset here only demonstrates syntax; choose Gamma because of the response distribution, not because a variable happens to be positive. Note that base R’s default Gamma link is inverse, so request link = "log" explicitly when multiplicative interpretation is intended.

Tweedie for a mass at zero plus positive continuous values

For power parameter between 1 and 2, the Tweedie distribution combines a point mass at zero with positive continuous values. Insurance cost and rainfall are common examples.

fit_tweedie <- glm(
  cost ~ treatment + age,
  family = statmod::tweedie(var.power = 1.5, link.power = 0),
  data = claims
)

link.power = 0 requests a log link. The overview’s glm(family=tweedie) is shorthand: an actual family object and power parameters are required. cplm::cpglm() and cplm::cpglmm() estimate compound Poisson/Tweedie models with fixed or mixed effects; glmmTMB(family = tweedie()) is another mixed-model route.

11. Censoring, truncation, and Tobit models

These terms describe different observation processes:

  • Censoring: the latent value exists, but values beyond a limit are recorded at that limit or only known to lie beyond it.
  • Truncation: observations beyond a limit are absent from the sample.
  • Transformation: taking a logarithm changes scale but does not model censoring or truncation.

Left-censored Tobit example

set.seed(11)
tobit_dat <- data.frame(x = rnorm(300))
tobit_dat$latent <- 1 + 2 * tobit_dat$x + rnorm(300)
tobit_dat$observed <- pmax(0, tobit_dat$latent)

fit_tobit <- censReg::censReg(
  observed ~ x,
  left = 0,
  right = Inf,
  data = tobit_dat
)

# Equivalent high-level interface:
fit_tobit_aer <- AER::tobit(
  observed ~ x,
  left = 0,
  data = tobit_dat
)

Do not use Tobit merely because observed values include many zeros. It assumes a latent Gaussian regression censored at a known threshold. VGAM::vglm(family = tobit()) provides related censored models; truncated families must match a sample-selection process in which excluded values are never observed.

12. Nonlinear mean functions

gaussian(link = "log") is a GLM with a nonlinear response-scale mean but remains linear in coefficients on the link scale. nls() is for a genuinely nonlinear parameterization specified directly by an equation.

DNase1 <- subset(DNase, Run == 1)

fit_nls <- nls(
  density ~ SSlogis(log(conc), Asym, xmid, scal),
  data = DNase1
)

summary(fit_nls)
coef(fit_nls)
predict(fit_nls, newdata = data.frame(conc = c(1, 4, 8)))

Self-starting functions such as SSlogis() provide initial values and gradients. For custom equations, supply scientifically plausible starts and examine parameter identifiability. Grouped nonlinear models can be fitted with nlme::nlme() or lme4::nlmer().

13. Compositions and Dirichlet regression

A composition contains several positive components that sum to one. Modelling each share independently ignores the unit-sum constraint and induces incoherent predictions.

data("ArcticLake", package = "DirichletReg")
ALake <- ArcticLake
ALake$Y <- DirichletReg::DR_data(ALake[, 1:3])

fit_dirichlet <- DirichletReg::DirichReg(
  Y ~ depth + I(depth^2) | depth,
  data = ALake,
  model = "alternative"
)

summary(fit_dirichlet)

In the alternative parameterization, the first formula part models expected component shares and the second models precision. Dirichlet observations are normally strictly positive; structural zeros require a different compositional strategy. The Bayesian counterpart is brm(family = dirichlet()).

14. Time-to-event outcomes and Cox regression

Survival data combine a time and an event indicator. Right-censored subjects contribute information up to their last observed time.

fit_cox <- survival::coxph(
  survival::Surv(time, status == 2) ~ age + sex,
  data = survival::lung,
  x = TRUE
)

summary(fit_cox)
exp(coef(fit_cox))

# Proportional-hazards diagnostic
ph_check <- survival::cox.zph(fit_cox)
ph_check
plot(ph_check)

Exponentiated coefficients are hazard ratios under the proportional-hazards assumption. They are not risk ratios and do not directly give absolute survival probabilities. Use survfit(fit_cox, newdata = ...) for estimated survival curves.

The overview labels coxph as a package/function entry; the current function is survival::coxph(). Clustered survival models can use robust/cluster terms, frailty models, or coxme::coxme() depending on the design.

15. Mixed models: when and how

Mixed models add latent group-level effects to account for hierarchical or repeated observations.

Function Model
lme4::lmer() Gaussian linear mixed model.
lme4::glmer() GLMM for families such as binomial and Poisson.
lme4::glmer.nb() Negative-binomial GLMM.
lme4::nlmer() Nonlinear mixed-effects model.
nlme::lme() / nlme::nlme() Linear/nonlinear mixed models with flexible residual correlation or variance structures.
glmmTMB::glmmTMB() Broad GLMM family, including zero inflation and dispersion models.
ordinal::clmm() Cumulative-link ordinal mixed model.
MASS::glmmPQL() Penalized quasi-likelihood GLMM; historically useful but approximation limitations matter.
coxme::coxme() Cox mixed-effects model.

Random-effects syntax

(1 | site)                 # site-specific intercepts
(time | subject)           # correlated subject intercepts and slopes
(1 | school/classroom)     # classroom nested within school
(1 | subject) + (1 | item) # crossed subject and item intercepts

Warnings about singular fit or non-convergence are analysis results, not messages to suppress blindly. Check scaling, information per group, redundant correlations, boundary variance estimates, and whether the random-effects design is estimable.

16. glmmTMB as a family translator

glmmTMB() uses one formula for the conditional mean, ziformula for zero inflation, and dispformula for dispersion. Current family functions include:

Response mechanism family =
Poisson poisson()
Negative binomial, quadratic variance glmmTMB::nbinom2()
Negative binomial, linear variance glmmTMB::nbinom1()
Zero-truncated Poisson glmmTMB::truncated_poisson()
Zero-truncated negative binomial glmmTMB::truncated_nbinom2()
Continuous proportion in (0,1) glmmTMB::beta_family()
Binomial counts with extra dispersion glmmTMB::betabinomial()
Closed-interval continuous proportion glmmTMB::ordbeta()
Semicontinuous positive response glmmTMB::tweedie() 
# Optional package: glmmTMB
fit_nb_mixed <- glmmTMB::glmmTMB(
  count ~ treatment + (1 | site),
  family = glmmTMB::nbinom2(),
  data = dat
)

fit_zi_mixed <- glmmTMB::glmmTMB(
  count ~ treatment + (1 | site),
  ziformula = ~ treatment,
  dispformula = ~ 1,
  family = glmmTMB::nbinom2(),
  data = dat
)

A zero-inflation formula does not make a model better by default. It adds another estimated process that needs adequate observations, interpretable predictors, and diagnostic support.

17. brms Bayesian equivalents

brms::brm() keeps R formula conventions and changes inference to Bayesian sampling through Stan. It supports fixed, multilevel, distributional, nonlinear, multivariate, and many specialized response families.

Model translations

Frequentist idea brms family
Gaussian gaussian()
Binary/trials bernoulli() / binomial()
Poisson count poisson()
Negative-binomial count negbinomial()
Zero-inflated count zero_inflated_poisson() / zero_inflated_negbinomial()
Hurdle count hurdle_poisson() / hurdle_negbinomial()
Continuous proportion Beta()
Exact 0/1 from separate states zero_one_inflated_beta()
Ordered category cumulative()
Unordered category categorical() / multinomial()
Composition dirichlet()
Survival cox() or parametric survival families. 
# Optional heavyweight package: brms
fit_bayes_nb <- brms::brm(
  count ~ treatment + (1 | site),
  family = brms::negbinomial(),
  data = dat,
  prior = c(
    brms::prior(normal(0, 1), class = "b"),
    brms::prior(exponential(1), class = "sd")
  ),
  chains = 4,
  cores = 4,
  seed = 20260811
)

brms::pp_check(fit_bayes_nb)
summary(fit_bayes_nb)

Bayesian fitting is not just replacing a function call. Specify and justify priors, inspect convergence (Rhat, effective sample size, divergences), perform prior and posterior predictive checks, and report posterior intervals and predictions.

18. Prediction, interpretation, and diagnostics

Prefer response-scale quantities

prediction_grid <- data.frame(
  wt = seq(min(mtcars$wt), max(mtcars$wt), length.out = 50),
  hp = median(mtcars$hp)
)

link_pred <- predict(
  fit_logit,
  newdata = prediction_grid,
  type = "link",
  se.fit = TRUE
)

prediction_grid$probability <- plogis(link_pred$fit)
prediction_grid$lower <- plogis(link_pred$fit - 1.96 * link_pred$se.fit)
prediction_grid$upper <- plogis(link_pred$fit + 1.96 * link_pred$se.fit)

Confidence intervals should be constructed on a scale where the approximation is valid, then transformed. For nonlinear, mixed, zero-inflated, ordinal, or Bayesian models, use class-aware prediction or marginal-effects tools rather than assuming the GLM recipe applies unchanged.

Model-specific checks

Model Essential checks
Linear Residual pattern, nonlinearity, heteroskedasticity, influence, prediction support.
Logistic/binomial Separation, calibration, nonlinear logit, denominator, discrimination if relevant.
Count Dispersion, zeros, exposure offset, residual structure, influential counts.
Zero-inflated/hurdle Both components, predicted zero rate, identifiability, component-specific predictors.
Beta Boundary mechanism, mean and precision fit, quantile residuals.
Ordinal Category order, sparse cells, proportional-odds/parallel-effects assumption.
Mixed Convergence, singularity, group sizes, random-effect distribution, conditional residuals.
Cox Proportional hazards, functional form, influential subjects, censoring assumptions.
Bayesian Priors, Rhat, ESS, divergences, posterior predictive fit, sensitivity.

Compare only comparable likelihoods

# Same response, same rows, nested or scientifically comparable formulas
AIC(model_1, model_2)
anova(model_1, model_2, test = "Chisq")

Do not compare AIC across different responses, different data subsets, or quasi-likelihood models. A smaller AIC does not validate the observation mechanism, causal assumptions, zero process, random-effects design, or out-of-sample calibration.

20. Model-selection checklist and common mistakes

Checklist

  1. Write the response support and observation mechanism in words.
  2. Preserve denominators, exposure time, censoring indicators, category order, and group IDs.
  3. Plot the response and inspect zeros, boundaries, sparse categories, and group sizes.
  4. Define the mean structure and nonlinearities independently of the response family.
  5. Choose the family and link from the data-generating process.
  6. Add random effects or another dependence strategy from the design.
  7. Fit a simple reference model before adding zero, dispersion, or distributional components.
  8. Diagnose every component and inspect response-scale predictions.
  9. Run scientifically motivated sensitivity analyses.
  10. Record package versions, contrasts, reference levels, and preprocessing decisions.

Common mistakes

  • Modelling count proportions with beta regression while discarding known denominators.
  • Using Poisson despite severe conditional overdispersion, or assuming negative binomial fixes all lack of fit.
  • Adding zero inflation solely because observed zeros look numerous.
  • Treating 0/1 boundaries as structural when they are censoring, or vice versa.
  • Converting an ordered factor to numeric and interpreting equal category gaps.
  • Ignoring clustering because fixed effects are statistically significant.
  • Reporting link-scale coefficients without probabilities, rates, or predicted categories.
  • Comparing quasi-likelihood models by ordinary AIC.
  • Interpreting a hazard ratio as a risk ratio.
  • Treating a successful optimizer exit as evidence that model assumptions are correct.

21. Installation and reproducibility

Install only the packages needed for the chosen model:

install.packages(c(
  "MASS", "nnet", "pscl", "betareg", "ordinal",
  "VGAM", "DirichletReg", "survival"
))

# Optional mixed-model ecosystem
install.packages(c("lme4", "glmmTMB", "coxme"))

# Optional Bayesian ecosystem; installation and model compilation are heavier
install.packages("brms")

At the end of an analysis:

sessionInfo()
saveRDS(fit, "model_fit.rds")

Serialized fitted objects may depend on package versions and compiled libraries. Save the analysis code, cleaned input or data recipe, session information, and prediction grid—not only the model object.

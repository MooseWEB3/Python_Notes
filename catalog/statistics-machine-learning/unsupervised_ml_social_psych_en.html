How to Use This Tutorial

Unsupervised machine learning searches for structure without a pre-labeled outcome. In sociology and psychology, it can help researchers explore social types, response profiles, latent dimensions, themes in text, network communities, and unusual cases. It does not automatically discover natural or causal categories.

This tutorial combines conceptual guidance with parallel R and Python examples. The data are simulated, the code is displayed rather than executed during HTML generation, and every substantive result still requires theory, measurement knowledge, robustness checks, and ethical review.

Treat unsupervised results as proposals for interpretation. A cluster number is an algorithmic assignment, not a diagnosis, identity, or intrinsic social group.

Learning Goals

You will learn to:

  • Match an unsupervised method to a sociological or psychological question;
  • Prepare survey, scale, text, mixed-type, and network data responsibly;
  • Use k-means, hierarchical clustering, Gaussian mixtures, PCA, exploratory factor analysis, MDS, topic models, community detection, and anomaly detection;
  • Evaluate stability, separation, sensitivity, and external meaning without turning an exploratory analysis into a confirmatory claim;
  • Report uncertainty, researcher choices, subgroup risks, and ethical limitations.

These methods can create labels that affect real people. Do not use exploratory clusters to make clinical, employment, educational, policing, immigration, or benefit decisions without appropriate validation, governance, human review, and legal/ethical safeguards.

1. What Counts as Unsupervised Learning?

Supervised learning predicts a known target such as depression diagnosis or voting intention. Unsupervised learning instead asks whether the measurements themselves contain useful organization.

Task Unit being organized Example question Common methods
Case clustering People, households, schools, neighborhoods Are there distinct patterns of civic participation and isolation? k-means, hierarchical, mixture models
Variable reduction Survey items or indicators Can 18 attitude items be summarized by fewer dimensions? PCA, factor analysis
Text structure Documents, posts, interview excerpts What themes recur in open-ended responses? topic models, embeddings + clustering
Relational structure People or organizations linked by ties Are there communities in a friendship or collaboration network? modularity, spectral methods
Unusual-case detection Respondents or observations Which response patterns require data-quality review? robust distance, isolation forest

1.1 Sociology Applications

  • Construct exploratory lifestyle, class-position, civic-participation, migration, or neighborhood profiles;
  • Compare welfare attitudes without assuming a single left-right axis;
  • Discover themes in interviews, policy documents, parliamentary speeches, or social-media corpora;
  • Detect communities and brokerage positions in organizational or interpersonal networks;
  • Find municipalities with unusual combinations of inequality, housing, and health indicators.

1.2 Psychology Applications

  • Explore symptom, coping, emotion-regulation, attachment, or personality profiles;
  • Examine whether many scale items reflect a smaller number of dimensions;
  • Identify trajectory shapes after repeated-measure features have been constructed;
  • Organize experience-sampling days or participants by behavioral patterns;
  • Flag careless responses for review using completion time, long strings, inconsistency, and multivariate distance.

1.3 What It Cannot Establish

Unsupervised learning alone cannot show that:

  • A discovered cluster exists as a discrete kind in the population;
  • Cluster membership causes an outcome;
  • The chosen number of groups is uniquely correct;
  • A visualization preserves every meaningful relationship;
  • A latent factor is psychologically real merely because a loading is large;
  • A topic label is objective rather than a researcher’s interpretation.

2. Research Design Before Algorithms

2.1 Define the Unit, Construct, and Intended Use

  1. Unit: Are rows people, observations within people, households, schools, documents, or nodes?
  2. Construct: Which concepts should the variables represent, and what evidence supports their measurement?
  3. Scope: Is the goal description, hypothesis generation, measurement development, sampling, or prediction support?
  4. Use: Who will see the labels, and could those labels allocate resources or stigma?
  5. Validation: What new sample, time point, qualitative evidence, or external variable can challenge the result?

2.2 Avoid Leakage From Future Interpretations

Even without a target, leakage can occur. If the goal is to create baseline well-being profiles, do not include a future hospitalization variable in clustering. Keep later outcomes outside the algorithm and use them only for cautious external validation.

2.3 Weights, Complex Samples, and Dependence

National surveys may use stratification, clusters, and unequal selection probabilities. Standard clustering functions usually ignore that design. Decide whether the analysis describes the collected sample or a target population; consider weighted summaries, replicate-weight sensitivity analyses, and multilevel structure. Repeated observations from the same person should not be treated as independent cases without first defining person-level features or using an appropriate longitudinal method.

3. A Reusable Simulated Study

We will simulate social-connectedness and psychological well-being measurements. The hidden profile is retained only to check the teaching simulation; a real unsupervised analysis would not know it.

3.1 Recommended Setup

Base R covers many examples. Install the optional packages when you reach mixture, text, or network analysis:

install.packages(c("mclust", "quanteda", "topicmodels", "igraph"))

For Python, create an environment and install the scientific stack:

python -m pip install numpy pandas scipy scikit-learn matplotlib networkx

Record package versions with sessionInfo() in R and python -m pip freeze in Python when producing a reproducible report.

3.2 R Data

set.seed(731)
n <- 360
profile_truth <- sample(c("connected", "strained", "withdrawn"), n,
                        replace = TRUE, prob = c(.42, .34, .24))

profile_means <- rbind(
  connected = c(trust = 4.3, participation = 4.0, loneliness = 1.8,
                stress = 2.2, efficacy = 4.1, sleep = 4.0),
  strained  = c(trust = 3.1, participation = 3.3, loneliness = 3.4,
                stress = 4.2, efficacy = 3.0, sleep = 2.5),
  withdrawn = c(trust = 2.2, participation = 1.7, loneliness = 4.4,
                stress = 3.5, efficacy = 2.3, sleep = 2.8)
)

survey <- as.data.frame(t(vapply(profile_truth, function(g) {
  pmin(5, pmax(1, rnorm(6, profile_means[g, ], .55)))
}, numeric(6))))
names(survey) <- colnames(profile_means)
survey$id <- sprintf("P%03d", seq_len(n))
survey$age <- round(pmin(80, pmax(18, rnorm(n, 41, 14))))
survey$region <- factor(sample(c("urban", "suburban", "rural"), n, TRUE,
                               prob = c(.50, .30, .20)))
survey$truth_for_simulation <- profile_truth
head(survey)

3.3 Python Data

import numpy as np
import pandas as pd

rng = np.random.default_rng(731)
n = 360
profiles = np.array(["connected", "strained", "withdrawn"])
truth = rng.choice(profiles, size=n, p=[0.42, 0.34, 0.24])

means = {
    "connected": [4.3, 4.0, 1.8, 2.2, 4.1, 4.0],
    "strained":  [3.1, 3.3, 3.4, 4.2, 3.0, 2.5],
    "withdrawn": [2.2, 1.7, 4.4, 3.5, 2.3, 2.8],
}
features = ["trust", "participation", "loneliness",
            "stress", "efficacy", "sleep"]

X = np.vstack([rng.normal(means[group], 0.55) for group in truth])
X = np.clip(X, 1, 5)
survey = pd.DataFrame(X, columns=features)
survey["id"] = [f"P{i:03d}" for i in range(1, n + 1)]
survey["age"] = np.clip(np.rint(rng.normal(41, 14, n)), 18, 80)
survey["region"] = rng.choice(["urban", "suburban", "rural"], n,
                              p=[0.50, 0.30, 0.20])
survey["truth_for_simulation"] = truth
survey.head()

The two language examples generate comparable but not byte-identical random data. They are independent workflows, not a promise of identical numerical output.

4. Data Preparation Is Part of the Model

4.1 Choose Features From Theory

Feature selection determines the meaning of distance. If twenty anxiety items and two social-support items enter clustering separately, anxiety dominates partly because it has more columns. Consider validated scale scores, domain-balanced features, or explicit feature weights.

Do not include IDs. Be careful with protected attributes: excluding ethnicity or gender from fitting does not guarantee fairness because other variables may act as proxies. Keep demographic variables available for auditing cluster composition.

4.2 Scale Continuous Features

Euclidean methods are sensitive to units. Age measured in years can dominate a 1-5 scale unless variables are standardized.

cluster_vars <- c("trust", "participation", "loneliness",
                  "stress", "efficacy", "sleep")
X <- scale(survey[cluster_vars])
attr(X, "scaled:center")
attr(X, "scaled:scale")
from sklearn.preprocessing import StandardScaler

features = ["trust", "participation", "loneliness",
            "stress", "efficacy", "sleep"]
scaler = StandardScaler()
X = scaler.fit_transform(survey[features])

4.3 Missing Data

Complete-case deletion changes the population if missingness relates to distress, literacy, language, or access. Median imputation is convenient for demonstrations but understates uncertainty. In substantive work, examine missingness by subgroup, consider multiple imputation, and repeat the complete unsupervised pipeline across imputed datasets.

# Simple demonstration only: median within each feature
median_fill <- function(x) replace(x, is.na(x), median(x, na.rm = TRUE))
survey[cluster_vars] <- lapply(survey[cluster_vars], median_fill)
from sklearn.impute import SimpleImputer

imputer = SimpleImputer(strategy="median")
X_imputed = imputer.fit_transform(survey[features])
X = StandardScaler().fit_transform(X_imputed)

4.4 Mixed Data and Gower Distance

For numeric, ordinal, nominal, and binary features together, Gower distance is often more defensible than arbitrary dummy coding plus Euclidean distance.

library(cluster)
mixed <- survey[c("age", "region", "trust", "loneliness")]
gower_distance <- daisy(mixed, metric = "gower")
gower_fit <- hclust(gower_distance, method = "average")
plot(gower_fit, labels = FALSE, main = "Gower-distance hierarchy")

Python users can install gower, or implement a documented mixed-distance workflow. Inspect how ordinal variables and asymmetric binaries are encoded rather than accepting defaults blindly.

5. k-Means: Exploratory Social Profiles

k-means divides cases into kk groups by minimizing squared Euclidean distance to cluster centroids. It works best for compact, roughly spherical groups on scaled numeric features.

5.1 Fit Several Values of k in R

set.seed(902)
k_grid <- 2:7
fits <- lapply(k_grid, function(k) {
  kmeans(X, centers = k, nstart = 50, iter.max = 200)
})

within_ss <- vapply(fits, function(fit) fit$tot.withinss, numeric(1))
plot(k_grid, within_ss, type = "b", pch = 19,
     xlab = "Number of clusters", ylab = "Total within-cluster SS")

chosen_r <- fits[[which(k_grid == 3)]]
survey$cluster_k3 <- factor(chosen_r$cluster)
aggregate(survey[cluster_vars], list(cluster = survey$cluster_k3), mean)

5.2 Python Equivalent

from sklearn.cluster import KMeans
import matplotlib.pyplot as plt

k_values = range(2, 8)
models = [KMeans(n_clusters=k, n_init=50, random_state=902).fit(X)
          for k in k_values]

plt.plot(list(k_values), [model.inertia_ for model in models], marker="o")
plt.xlabel("Number of clusters")
plt.ylabel("Total within-cluster sum of squares")
plt.show()

model_k3 = models[list(k_values).index(3)]
survey["cluster_k3"] = model_k3.labels_.astype(str)
print(survey.groupby("cluster_k3")[features].mean().round(2))

5.3 Interpret Profiles, Not Cluster Numbers

Centroid tables matter more than labels 1, 2, and 3, whose numbering is arbitrary. Name a profile only after examining all defining variables. Use neutral descriptions such as “lower participation / higher loneliness,” not value-laden names such as “failed integrators.”

k-means will return clusters even for a single continuous cloud. Its successful execution is not evidence that discrete social types exist.

6. Hierarchical Clustering: Nested Similarities

Hierarchical clustering is useful when researchers want a tree of nested similarities or have a modest sample. Agglomerative methods begin with individual cases and merge them step by step.

6.1 R With Ward Linkage

distance_r <- dist(X, method = "euclidean")
tree_r <- hclust(distance_r, method = "ward.D2")
plot(tree_r, labels = FALSE, hang = -1,
     main = "Hierarchy of respondent profiles")
rect.hclust(tree_r, k = 3, border = c("#6d5dfc", "#19c3d2", "#20a36a"))

survey$cluster_hier <- factor(cutree(tree_r, k = 3))
table(kmeans = survey$cluster_k3, hierarchical = survey$cluster_hier)

6.2 Python With a Dendrogram

from scipy.cluster.hierarchy import linkage, dendrogram, fcluster
import matplotlib.pyplot as plt

linkage_matrix = linkage(X, method="ward", metric="euclidean")
dendrogram(linkage_matrix, no_labels=True, color_threshold=None)
plt.xlabel("Respondents")
plt.ylabel("Merge distance")
plt.show()

survey["cluster_hier"] = fcluster(linkage_matrix, t=3, criterion="maxclust")
print(pd.crosstab(survey["cluster_k3"], survey["cluster_hier"]))

Ward linkage is tied to squared Euclidean geometry. For Gower distance, use average or complete linkage instead. Single linkage often produces long “chains” and is rarely a good default for respondent profiles.

7. Gaussian Mixtures and Latent Profiles

A Gaussian mixture model treats the observed distribution as a weighted combination of multivariate normal components. It returns probabilities of membership rather than only hard assignments. In psychological research, continuous-indicator mixture models are often called latent profile analysis (LPA); categorical-indicator models are latent class analysis (LCA).

7.1 R With mclust

# install.packages("mclust")
library(mclust)

mixture_r <- Mclust(X, G = 1:6)
summary(mixture_r)
plot(mixture_r, what = "BIC")

survey$mixture_class <- factor(mixture_r$classification)
survey$membership_uncertainty <- mixture_r$uncertainty
aggregate(membership_uncertainty ~ mixture_class, survey, mean)

7.2 Python With GaussianMixture

from sklearn.mixture import GaussianMixture

candidates = [
    GaussianMixture(n_components=k, covariance_type="full",
                    n_init=20, random_state=44).fit(X)
    for k in range(1, 7)
]
bic = [model.bic(X) for model in candidates]
best = candidates[int(np.argmin(bic))]

membership_prob = best.predict_proba(X)
survey["mixture_class"] = best.predict(X)
survey["membership_uncertainty"] = 1 - membership_prob.max(axis=1)
print(pd.Series(bic, index=range(1, 7), name="BIC"))

Use BIC, entropy/uncertainty, class size, interpretability, convergence from multiple starts, and replication together. A tiny class may be a meaningful rare profile, an outlier collection, or a local optimum. Mixture assumptions do not convert convenience samples into population evidence.

8. PCA: Summarizing Correlated Indicators

Principal component analysis creates weighted combinations that explain maximum variance. It is useful for compression, visualization, and reducing collinearity. PCA is not a measurement model and does not separate shared variance from item-specific/error variance.

8.1 R PCA

pca_r <- prcomp(survey[cluster_vars], center = TRUE, scale. = TRUE)
summary(pca_r)
round(pca_r$rotation[, 1:3], 2)

plot(pca_r, type = "l", main = "PCA scree plot")
biplot(pca_r, choices = c(1, 2), cex = .55)

8.2 Python PCA

from sklearn.decomposition import PCA

pca = PCA().fit(X)
scores = pca.transform(X)
loadings = pd.DataFrame(
    pca.components_.T,
    index=features,
    columns=[f"PC{i}" for i in range(1, len(features) + 1)]
)
print(pca.explained_variance_ratio_.round(3))
print(loadings.iloc[:, :3].round(2))

Component signs are arbitrary: multiplying a component and its scores by -1 changes no fit. Interpret patterns, not sign conventions. Decide the number of components using scree shape, parallel analysis, out-of-sample reconstruction, and substantive usefulness rather than the eigenvalue-greater-than-one rule alone.

9. Exploratory Factor Analysis for Psychological Constructs

Exploratory factor analysis (EFA) models correlations as arising from latent common factors plus item-specific variance. This makes it more natural than PCA for investigating constructs, but it remains exploratory and depends on item quality, extraction, rotation, factor count, and sample.

9.1 Simulate Eight Items in R

set.seed(118)
n_items <- 520
social_latent <- rnorm(n_items)
distress_latent <- rnorm(n_items, sd = .9)

items <- data.frame(
  belong1 = .78 * social_latent + rnorm(n_items, 0, .55),
  belong2 = .72 * social_latent + rnorm(n_items, 0, .62),
  belong3 = .68 * social_latent + rnorm(n_items, 0, .65),
  support1 = .62 * social_latent + rnorm(n_items, 0, .70),
  worry1 = .80 * distress_latent + rnorm(n_items, 0, .52),
  worry2 = .75 * distress_latent + rnorm(n_items, 0, .58),
  tension1 = .70 * distress_latent + rnorm(n_items, 0, .64),
  sleep_problem = .50 * distress_latent - .18 * social_latent +
                  rnorm(n_items, 0, .76)
)

efa_r <- factanal(items, factors = 2, rotation = "promax", scores = "regression")
print(efa_r$loadings, cutoff = .25, sort = TRUE)

9.2 Python Factor Analysis

from sklearn.decomposition import FactorAnalysis
from sklearn.preprocessing import StandardScaler

rng_items = np.random.default_rng(118)
n_items = 520
social_latent = rng_items.normal(size=n_items)
distress_latent = rng_items.normal(scale=0.9, size=n_items)
items_df = pd.DataFrame({
    "belong1": 0.78 * social_latent + rng_items.normal(0, 0.55, n_items),
    "belong2": 0.72 * social_latent + rng_items.normal(0, 0.62, n_items),
    "belong3": 0.68 * social_latent + rng_items.normal(0, 0.65, n_items),
    "support1": 0.62 * social_latent + rng_items.normal(0, 0.70, n_items),
    "worry1": 0.80 * distress_latent + rng_items.normal(0, 0.52, n_items),
    "worry2": 0.75 * distress_latent + rng_items.normal(0, 0.58, n_items),
    "tension1": 0.70 * distress_latent + rng_items.normal(0, 0.64, n_items),
    "sleep_problem": 0.50 * distress_latent - 0.18 * social_latent
                     + rng_items.normal(0, 0.76, n_items),
})

item_names = ["belong1", "belong2", "belong3", "support1",
              "worry1", "worry2", "tension1", "sleep_problem"]
Z_items = StandardScaler().fit_transform(items_df[item_names])

fa = FactorAnalysis(n_components=2, rotation="varimax", random_state=118)
factor_scores = fa.fit_transform(Z_items)
loadings = pd.DataFrame(fa.components_.T,
                        index=item_names,
                        columns=["Factor1", "Factor2"])
print(loadings.round(2))

For ordinal Likert items with few categories, consider polychoric correlations and robust estimators. After EFA, confirm the proposed structure in a new sample using confirmatory factor analysis; do not tune and confirm on the same observations.

10. MDS, t-SNE, and UMAP for Visualization

Multidimensional scaling (MDS) places objects in a low-dimensional map that approximates distances. It can visualize similarities among occupations, values, neighborhoods, or respondents.

occupation_distance <- matrix(c(
  0, 2, 5, 6, 7,
  2, 0, 4, 5, 6,
  5, 4, 0, 2, 3,
  6, 5, 2, 0, 2,
  7, 6, 3, 2, 0
), nrow = 5, byrow = TRUE)
rownames(occupation_distance) <- colnames(occupation_distance) <-
  c("teacher", "nurse", "engineer", "programmer", "scientist")

mds_r <- cmdscale(as.dist(occupation_distance), k = 2, eig = TRUE)
plot(mds_r$points, type = "n", xlab = "Dimension 1", ylab = "Dimension 2")
text(mds_r$points, labels = rownames(occupation_distance))
from sklearn.manifold import MDS
import matplotlib.pyplot as plt

labels = ["teacher", "nurse", "engineer", "programmer", "scientist"]
D = np.array([
    [0, 2, 5, 6, 7], [2, 0, 4, 5, 6], [5, 4, 0, 2, 3],
    [6, 5, 2, 0, 2], [7, 6, 3, 2, 0]
])
coords = MDS(n_components=2, metric="precomputed",
             random_state=12, normalized_stress="auto").fit_transform(D)
plt.scatter(coords[:, 0], coords[:, 1])
for label, (x, y) in zip(labels, coords):
    plt.text(x, y, label)
plt.show()

t-SNE and UMAP are powerful nonlinear visualizers, but distances between distant groups, cluster sizes, and apparent gaps can be misleading. Re-run several seeds and parameter settings. Never choose kk merely by counting islands in a t-SNE/UMAP plot.

11. Topic Models for Interviews and Open Responses

Topic models represent documents as mixtures of word distributions. They can assist with corpus navigation and comparison, but they do not replace close reading or qualitative coding.

11.1 R LDA Workflow

# install.packages(c("quanteda", "topicmodels"))
library(quanteda)
library(topicmodels)

responses <- c(
  "Rent increases make it hard to remain near family",
  "The bus is unreliable and the commute limits my work",
  "Neighbors organize childcare and share groceries",
  "I feel isolated since community programs closed",
  "Flexible work helps but housing costs keep rising",
  "Local groups provide support and social connection"
)

tokens_r <- tokens(responses, remove_punct = TRUE) |>
  tokens_tolower() |>
  tokens_remove(stopwords("en"))
dfm_r <- dfm(tokens_r) |> dfm_trim(min_termfreq = 1)
lda_r <- LDA(convert(dfm_r, to = "topicmodels"), k = 2,
             control = list(seed = 87))
terms(lda_r, 5)
posterior(lda_r)$topics

11.2 Python LDA Workflow

from sklearn.feature_extraction.text import CountVectorizer
from sklearn.decomposition import LatentDirichletAllocation

responses = [
    "Rent increases make it hard to remain near family",
    "The bus is unreliable and the commute limits my work",
    "Neighbors organize childcare and share groceries",
    "I feel isolated since community programs closed",
    "Flexible work helps but housing costs keep rising",
    "Local groups provide support and social connection",
]

vectorizer = CountVectorizer(stop_words="english", min_df=1)
document_term = vectorizer.fit_transform(responses)
lda = LatentDirichletAllocation(n_components=2, random_state=87,
                                learning_method="batch").fit(document_term)
terms = np.array(vectorizer.get_feature_names_out())
for topic_id, weights in enumerate(lda.components_):
    print(topic_id, terms[np.argsort(weights)[-6:][::-1]])

The corpus above is intentionally tiny for readable code; real topic models need substantially more documents. Audit tokenization, language, spelling, stopwords, document length, and who is absent. Interpret topics by reading high-probability and high-exclusivity documents, negative cases, and excerpts in context. Human-created labels should be presented as interpretations.

12. Community Detection in Social Networks

Network communities are sets of nodes with relatively dense internal ties. They are relational structures, not clusters from independent survey rows.

12.1 R With igraph

# install.packages("igraph")
library(igraph)

ties <- data.frame(
  from = c("A","A","B","B","C","D","D","E","E","F","C"),
  to   = c("B","C","C","D","D","E","F","F","G","G","E")
)
network_r <- graph_from_data_frame(ties, directed = FALSE)
communities_r <- cluster_louvain(network_r)
membership(communities_r)
modularity(communities_r)
plot(communities_r, network_r)

12.2 Python With networkx

import networkx as nx

ties = [("A","B"), ("A","C"), ("B","C"), ("B","D"),
        ("C","D"), ("D","E"), ("D","F"), ("E","F"),
        ("E","G"), ("F","G"), ("C","E")]
graph = nx.Graph(ties)
communities = nx.community.louvain_communities(graph, seed=33)
print(communities)
print(nx.community.modularity(graph, communities))

Community results depend on which relationships were observed, boundary specification, edge weights, direction, resolution, and missing nodes. Modularity has a resolution limit and can produce multiple near-optimal partitions. Compare seeds and algorithms; incorporate network-generation theory.

13. Detecting Unusual Responses Without Labeling People

Anomaly detection can help review survey fraud, bots, impossible combinations, or careless responding. “Unusual” means unusual under the selected features and model; it does not mean dishonest, ill, or dangerous.

13.1 Robust-Distance Review in R

set.seed(55)
quality <- data.frame(
  minutes = c(rlnorm(195, log(12), .30), runif(5, .3, 1.2)),
  longstring = c(rpois(195, 4), sample(35:55, 5)),
  inconsistency = c(rbeta(195, 2, 12), runif(5, .75, 1))
)

quality_z <- scale(quality)
center <- colMeans(quality_z)
covariance <- cov(quality_z)
quality$distance <- mahalanobis(quality_z, center, covariance)
quality$review_flag <- quality$distance > qchisq(.995, df = ncol(quality_z))
subset(quality, review_flag)

14. Validation: The Essential Step

14.1 Internal Separation

Silhouette values compare within-cluster cohesion with nearest-cluster separation. Values near 1 indicate separation, near 0 indicate overlap, and negative values suggest possible misassignment.

library(cluster)
sil_r <- silhouette(chosen_r$cluster, dist(X))
summary(sil_r)
plot(sil_r, border = NA)
from sklearn.metrics import silhouette_score, silhouette_samples

print(silhouette_score(X, model_k3.labels_))
survey["silhouette"] = silhouette_samples(X, model_k3.labels_)

Internal indices reward particular geometry. Do not choose a model solely because it has the highest silhouette.

bootstrap_centers <- replicate(50, {
  rows <- sample(seq_len(nrow(X)), replace = TRUE)

from sklearn.metrics import adjusted_rand_score

rng = np.random.default_rng(99)
agreement = []
for _ in range(50):
    rows = rng.integers(0, len(X), len(X))
    boot_model = KMeans(n_clusters=3, n_init=30,
                        random_state=int(rng.integers(1_000_000))).fit(X[rows])
    # Compare predictions on the same full dataset to avoid duplicate-row alignment.
    agreement.append(adjusted_rand_score(
        model_k3.labels_, boot_model.predict(X)
    ))
print(pd.Series(agreement).describe())

The R snippet summarizes centroid variability after ordering by loneliness; the Python snippet evaluates adjusted Rand agreement on common cases. More formal stability tools can align labels and quantify membership probabilities.

14.3 External and Interpretive Validation

Keep external variables out of fitting, then ask whether profiles differ on theoretically relevant outcomes, behaviors, or qualitative accounts. Avoid circular validation: if loneliness defines clusters, strong loneliness differences do not validate them. Replicate in a new sample, time, site, or language group.

14.4 Sensitivity Grid

At minimum, vary:

  • Feature definitions and scale construction;
  • Scaling and transformations;
  • Missing-data treatment;
  • Distance metric and algorithm;
  • Number of clusters/components/topics;
  • Random seeds and starting values;
  • Inclusion of survey weights or sites;
  • Subgroups and time periods.

Report which interpretations survive these choices.

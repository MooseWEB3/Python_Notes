How to use this guide

Python is a general-purpose programming language used for automation, data analysis, web applications, scientific computing, artificial intelligence, testing, and command-line tools. Its syntax is approachable, but learning Python well still requires practice with problem decomposition, data modeling, debugging, and readable code.

This guide assumes no prior Python experience. Read it in order the first time, type the examples yourself, predict each result before running it, and then change one value or rule. Passive reading creates familiarity; editing and debugging create skill.

Learning goals

By the end, you will be able to:

  • install and run Python in the interactive shell and from scripts;
  • work with numbers, strings, booleans, and None;
  • store data in lists, tuples, sets, and dictionaries;
  • control program flow with conditions, loops, and comprehensions;
  • write reusable functions with clear inputs, outputs, and documentation;
  • handle expected failures with exceptions;
  • read and write text, JSON, and CSV files safely;
  • organize code into modules and isolated environments;
  • create simple classes and dataclasses;
  • use type hints, tests, logging, and debugging techniques;
  • build a complete command-line expense tracker.

Recommended version: Python 3.11 or newer. Most examples also work in slightly older versions, but modern type hints and standard-library features are easier to use in current Python.

1. Install Python and verify the environment

1.1 Check the installed version

Open PowerShell, Terminal, or another command shell and run:

Terminal
python --version

Some macOS and Linux installations use python3:

Terminal
python3 --version

A version such as Python 3.12.5 contains major, minor, and patch numbers. Avoid Python 2 tutorials; Python 2 has been unsupported for years and differs substantially from Python 3.

1.2 Locate the interpreter

Terminal
# Windows
where python

# macOS or Linux
which python3

The result identifies the executable your shell will use. This matters when several Python installations or virtual environments exist.

1.3 Your first program

Create hello.py:

Python
name = "Ada"
print(f"Hello, {name}!")

Run it from the directory containing the file:

Terminal
python hello.py

The .py file is a script. Python reads it from top to bottom, compiles it to bytecode, and executes the instructions.

2. Interactive shell, scripts, and notebooks

2.1 The interactive shell

Run python without a filename. The >>> prompt accepts one statement at a time.

Python
2 + 3
"python".upper()
len([10, 20, 30])

The shell is useful for experiments and checking documentation examples. Exit with exit() or the platform keyboard shortcut.

2.2 Scripts

Scripts preserve a sequence of operations and can be rerun. A common entry-point pattern is:

Python
def main() -> None:
    print("Program started")


if __name__ == "__main__":
    main()

When the file runs directly, __name__ equals "__main__". When another file imports it, the main() call does not run automatically.

2.3 Notebooks

Jupyter notebooks mix executable cells, prose, equations, and figures. They are excellent for exploration and teaching, but cell execution order can hide state. Restart and run all cells before sharing a notebook.

ToolBest useMain caution
Interactive shelltiny experimentswork is not organized
Scriptreusable program or automationrequires explicit output
Notebookexploration and explanationhidden state and execution order
IDE/editorlarger projectssetup can distract beginners

3. Syntax, indentation, and comments

3.1 Indentation creates blocks

Python uses indentation instead of braces to group statements.

Python
temperature = 18

if temperature < 20:
    message = "Bring a jacket"
    print(message)

print("Forecast checked")

The two indented lines belong to the if block. Use four spaces per indentation level and configure the editor to insert spaces consistently.

3.2 Comments explain why

Python
# The API reports cents, so convert once at the boundary.
price_cad = price_cents / 100

Comments should explain intent, constraints, or a non-obvious decision. Avoid comments that merely repeat the code.

3.3 Statements can span lines

Prefer parentheses for readable multi-line expressions.

Python
total = (
    item_price
    * quantity
    * (1 - discount_rate)
)

Python is case-sensitive: user_name, User_Name, and USER_NAME are different identifiers.

4. Values, types, variables, and identity

4.1 Common built-in types

Python
age = 28                  # int
price = 19.95             # float
name = "Mina"             # str
is_active = True          # bool
missing_value = None      # NoneType

print(type(age))
print(type(price))
print(type(name))

Python is dynamically typed: variables do not have fixed types, but every value does. A name can later refer to a different type, although frequent type changes make programs harder to understand.

4.2 Assignment binds a name

Python
first = [1, 2]
second = first
second.append(3)

print(first)          # [1, 2, 3]
print(first is second)  # True

Assignment does not automatically copy an object. Both names above refer to the same mutable list.

4.3 Equality versus identity

Python
a = [1, 2]
b = [1, 2]

print(a == b)   # True: equal contents
print(a is b)   # False: different objects
print(a is None)

Use == to compare values. Use is mainly for singleton objects such as None.

4.4 Naming conventions

KindConventionExample
Variable/functionsnake_caseorder_total

Internal detailleading underscore_cache

Names may contain letters, digits, and underscores but cannot start with a digit or use a reserved keyword.

5. Numbers and arithmetic

5.1 Numeric operators

Python
a = 17
b = 5

print(a + b)   # 22
print(a - b)   # 12
print(a * b)   # 85
print(a / b)   # 3.4 true division
print(a // b)  # 3 floor division
print(a % b)   # 2 remainder
print(a ** 2)  # 289 exponentiation

Parentheses make precedence explicit:

Python
subtotal = 80
tax_rate = 0.05
shipping = 10
total = subtotal * (1 + tax_rate) + shipping

5.2 Conversions and rounding

Python
count = int("42")
rate = float("0.15")
label = str(2026)

print(round(3.14159, 2))

Binary floating-point cannot represent every decimal exactly:

Python
print(0.1 + 0.2)  # commonly 0.30000000000000004

For money requiring exact decimal rules, use Decimal.

Python
from decimal import Decimal, ROUND_HALF_UP

price = Decimal("19.95")
quantity = 3
total = (price * quantity).quantize(Decimal("0.01"), rounding=ROUND_HALF_UP)
print(total)

5.3 Helpful numeric functions

Python
values = [8, 3, 11, 5]

print(min(values))
print(max(values))
print(sum(values))
print(abs(-12))
print(divmod(17, 5))  # quotient and remainder

6. Strings and text processing

6.1 Create and combine strings

Python
first_name = "Ada"
last_name = 'Lovelace'
full_name = first_name + " " + last_name
message = f"Welcome, {full_name}!"
print(message)

F-strings are the clearest way to embed expressions.

Python
price = 19.5
quantity = 3
print(f"Total: ${price * quantity:.2f}")

6.2 Indexing and slicing

Python
language = "Python"

print(language[0])    # P
print(language[-1])   # n
print(language[1:4])  # yth
print(language[:3])   # Pyt
print(language[::2])  # Pto

Indexes start at zero, and the slice stop is excluded. Strings are immutable: operations create new strings rather than changing the original.

6.3 Useful methods

Python
raw = "  Ada Lovelace  "
clean = raw.strip()

print(clean.lower())
print(clean.upper())
print(clean.replace("Ada", "Augusta"))
print(clean.startswith("Ada"))
print(clean.split())

Join many pieces with join():

Python
words = ["learn", "python", "daily"]
slug = "-".join(words)
print(slug)

6.4 Escapes and multi-line strings

Python
path = r"C:\Users\Ada\notes.txt"
line = "first\nsecond"
paragraph = """This text
continues across
multiple lines."""

Raw strings reduce backslash escaping, especially in Windows paths and regular expressions.

7. Input, output, and formatting

7.1 Read text from the user

Python
name = input("What is your name? ").strip()
print(f"Hello, {name or 'guest'}!")

input() always returns a string. Convert and validate numeric input.

Python
raw_age = input("Age: ")
age = int(raw_age)
print(f"Next year you will be {age + 1}.")

Invalid text raises ValueError; a later chapter handles this gracefully.

7.2 print() options

Python
print("red", "green", "blue", sep=" | ")
print("loading", end="...")
print("done")

Use format specifications for aligned reports.

Python
items = [("Notebook", 4.5), ("Keyboard", 79.99)]

for name, price in items:
    print(f"{name:<12} ${price:>8.2f}")

8. Booleans, comparisons, and truthiness

8.1 Comparison operators

Python
score = 82

print(score == 82)
print(score != 0)
print(score >= 60)
print(0 < score <= 100)

Python supports chained comparisons. Combine conditions with and, or, and not.

Python
age = 20
has_ticket = True
can_enter = age >= 18 and has_ticket
print(can_enter)

8.2 Truthy and falsy values

False, None, numeric zero, and empty containers are falsy. Most other values are truthy.

Python
names = []

if not names:
    print("No names were provided")

Truthiness is concise, but explicit comparisons can clarify domain meaning:

Python
balance = 0.0

if balance == 0:
    print("The account is exactly empty")

8.3 Short-circuit evaluation

Python
user = {"name": "Ada"}

if user and user.get("name"):
    print(user["name"])

For and, Python stops after the first falsy operand. For or, it stops after the first truthy operand.

9. Conditional logic

9.1 if, elif, and else

Python
score = 76

if score >= 90:
    grade = "A"
elif score >= 80:
    grade = "B"
elif score >= 70:
    grade = "C"
else:
    grade = "Needs improvement"

print(grade)

Order matters: Python executes the first true branch and skips the rest.

9.2 Conditional expressions

Python
temperature = 7
label = "cold" if temperature < 10 else "mild"

Use this form only for short, readable choices.

9.3 Structural pattern matching

Python 3.10+ supports match for structured alternatives.

Python
command = "list"

match command:
    case "add":
        action = "Create an item"
    case "list" | "show":
        action = "Display items"
    case "quit":
        action = "Exit"
    case _:
        action = "Unknown command"

For a few boolean conditions, if remains simpler.

10. Lists and tuples

10.1 Lists are ordered and mutable

Python
tasks = ["plan", "code", "test"]
tasks.append("review")
tasks.insert(1, "design")
completed = tasks.pop(0)

print(tasks)
print(completed)

Useful operations include:

Python
numbers = [5, 2, 9, 2]

print(len(numbers))
print(numbers.count(2))
print(9 in numbers)
print(sorted(numbers))      # new list
numbers.sort(reverse=True)  # changes the list

10.2 Copy lists intentionally

Python
original = [[1, 2], [3, 4]]
shallow = original.copy()
shallow[0].append(99)

print(original)  # nested list was shared

Use copy.deepcopy() only when independent nested copies are truly required.

10.3 Tuples are ordered and immutable

Python
location = (53.5461, -113.4938)
latitude, longitude = location

rgb = (30, 120, 200)
single = (42,)  # comma creates a one-item tuple

Tuples communicate a fixed record or grouping. Unpacking works with many iterables.

first, *middle, last = [10, 20, 30, 40]
print(first, middle, last)

11. Dictionaries and sets

11.1 Dictionaries map unique keys to values

Python
user = {
    "name": "Ada",
    "role": "analyst",
    "active": True,
}

print(user["name"])
print(user.get("email", "not provided"))

user["email"] = "ada@example.com"
user["role"] = "engineer"

Direct indexing raises KeyError for a missing key. get() supplies a default.

Python
for key, value in user.items():
    print(f"{key}: {value}")

11.2 Dictionary patterns

Python
word_counts: dict[str, int] = {}

for word in "to be or not to be".split():
    word_counts[word] = word_counts.get(word, 0) + 1

print(word_counts)

Merge dictionaries with | in modern Python:

Python
defaults = {"theme": "light", "page_size": 25}
user_settings = {"theme": "dark"}
settings = defaults | user_settings

11.3 Sets store unique hashable values

Python
tags = {"python", "data", "python"}
tags.add("testing")

required = {"python", "git"}
known = {"python", "sql"}

print(required & known)  # intersection
print(required | known)  # union
print(required - known)  # difference

Sets are ideal for membership checks, deduplication, and set algebra. They are not indexed sequences.

12. Loops and iteration

12.1 for loops

Python
names = ["Ada", "Grace", "Linus"]

for name in names:
    print(name.upper())

Use enumerate() when the position is needed.

Python
for position, name in enumerate(names, start=1):
    print(f"{position}. {name}")

Iterate over two sequences with zip():

Python
products = ["Tea", "Coffee", "Cocoa"]
prices = [4.5, 5.0, 4.75]

for product, price in zip(products, prices, strict=True):
    print(f"{product}: ${price:.2f}")

strict=True catches unequal lengths.

12.2 while loops

Python
attempts = 3

while attempts > 0:
    print(f"Attempts remaining: {attempts}")
    attempts -= 1

Ensure the condition can become false; otherwise the loop is infinite.

12.3 break, continue, and loop else

Python
values = [3, 7, 12, 18]

for value in values:
    if value % 2 != 0:
        continue
    if value > 10:
        print(f"Found: {value}")
        break
else:
    print("No matching value")

The loop else runs only if the loop finishes without break.

13. Comprehensions and generators

13.1 List comprehensions

Python
squares = [number ** 2 for number in range(1, 6)]
even_squares = [number ** 2 for number in range(1, 11) if number % 2 == 0]

Comprehensions are concise transformations. Use a normal loop when logic becomes difficult to read.

13.2 Dictionary and set comprehensions

Python
names = ["ada", "grace", "linus"]
lengths = {name: len(name) for name in names}
initials = {name[0].upper() for name in names}

13.3 Generator expressions

Python
values = range(1, 1_000_001)
sum_of_squares = sum(value * value for value in values)

A generator produces values lazily instead of building the entire collection in memory.

14. Functions

14.1 Define and call a function

Python
def calculate_total(price: float, quantity: int) -> float:
    """Return price multiplied by a non-negative quantity."""
    if quantity < 0:
        raise ValueError("quantity cannot be negative")
    return price * quantity


total = calculate_total(19.95, 3)

Parameters receive input; return sends a result to the caller. Without return, a function returns None.

14.2 Default and keyword arguments

Python
def greet(name: str, greeting: str = "Hello") -> str:
    return f"{greeting}, {name}!"


print(greet("Mina"))
print(greet("Mina", greeting="Welcome"))

Never use a mutable object as a default value.

Python
def add_tag(tag: str, tags: list[str] | None = None) -> list[str]:
    result = [] if tags is None else tags.copy()
    result.append(tag)
    return result

14.3 Variable arguments

Python
def average(*values: float) -> float:
    if not values:
        raise ValueError("at least one value is required")
    return sum(values) / len(values)


def build_profile(name: str, **details: str) -> dict[str, str]:
    return {"name": name, **details}

*args collects positional arguments into a tuple; **kwargs collects keyword arguments into a dictionary.

14.4 Scope

Python
tax_rate = 0.05  # module scope

def add_tax(amount: float) -> float:
    result = amount * (1 + tax_rate)  # local result, reads global tax_rate
    return result

Prefer passing changing values as parameters instead of modifying global state.

14.5 Functions as values

Python
def double(value: int) -> int:
    return value * 2


numbers = [1, 2, 3]
doubled = list(map(double, numbers))

Functions can be stored, passed, and returned. Comprehensions are often clearer than map() for simple transformations.

15. Errors and exceptions

15.1 Read tracebacks from the bottom

A traceback identifies the exception type and message at the bottom, then shows the call path. Find the first frame belonging to your code and inspect the relevant values.

15.2 Catch expected failures narrowly

Python
def parse_age(raw: str) -> int:
    try:
        age = int(raw)
    except ValueError as exc:
        raise ValueError("age must be a whole number") from exc

    if not 0 <= age <= 130:
        raise ValueError("age must be between 0 and 130")
    return age

Catch only exceptions you can handle or translate. Avoid except Exception: pass, which hides defects.

15.3 else and finally

Python
try:
    value = int("42")
except ValueError:
    print("Invalid integer")
else:
    print(f"Parsed: {value}")
finally:
    print("Parsing attempt finished")

else runs after a successful try; finally runs whether the operation succeeds or fails.

15.4 Custom exceptions

Python
class InsufficientFundsError(ValueError):
    """Raised when a withdrawal exceeds the available balance."""


def withdraw(balance: float, amount: float) -> float:
    if amount > balance:
        raise InsufficientFundsError("amount exceeds balance")
    return balance - amount

Custom exceptions make domain failures distinguishable from unrelated errors.

16. Modules, packages, and imports

16.1 Import standard-library modules

Python
import math
from statistics import mean

radius = 3
area = math.pi * radius ** 2
average_value = mean([10, 20, 30])

Avoid wildcard imports because they hide where names came from.

16.2 Create a module

conversions.py:

Python
def celsius_to_fahrenheit(celsius: float) -> float:
    return celsius * 9 / 5 + 32

main.py:

Python
from conversions import celsius_to_fahrenheit

print(celsius_to_fahrenheit(20))

16.3 Package structure

Text
weather_app/
├── pyproject.toml
├── src/
│   └── weather_app/
│       ├── __init__.py
│       ├── conversions.py
│       └── cli.py
└── tests/
    └── test_conversions.py

A package is a directory of related modules. Larger projects benefit from a src layout that prevents accidental imports from the project root.

17. Virtual environments and packages

17.1 Create an isolated environment

Terminal
python -m venv .venv

# Windows PowerShell
.venv\Scripts\Activate.ps1

# macOS or Linux
source .venv/bin/activate

After activation, python and pip refer to the project environment.

17.2 Install and inspect packages

Terminal
python -m pip install requests
python -m pip show requests
python -m pip list

Using python -m pip helps ensure pip belongs to the selected interpreter.

17.3 Declare dependencies

Modern projects commonly use pyproject.toml.

toml
[project]
name = "weather-app"
version = "0.1.0"
requires-python = ">=3.11"
dependencies = ["requests>=2.32,<3"]

[project.optional-dependencies]
dev = ["pytest>=8,<9", "ruff>=0.6,<1"]

Do not commit .venv. Commit dependency declarations and an appropriate lock file when reproducible application builds require one.

18. Files and paths

18.1 Use pathlib

Python
from pathlib import Path

data_dir = Path("data")
report_path = data_dir / "report.txt"

data_dir.mkdir(parents=True, exist_ok=True)
report_path.write_text("Python report\n", encoding="utf-8")
content = report_path.read_text(encoding="utf-8")

Path handles separators across operating systems and provides readable file operations.

18.2 Context managers

Python
from pathlib import Path

path = Path("notes.txt")

with path.open("a", encoding="utf-8") as file:
    file.write("A new note\n")

The with block closes the file even if an exception occurs.

19. JSON and CSV data

19.1 JSON

Python
import json
from pathlib import Path

settings = {"theme": "dark", "page_size": 25, "alerts": True}
path = Path("settings.json")

path.write_text(json.dumps(settings, indent=2), encoding="utf-8")
loaded = json.loads(path.read_text(encoding="utf-8"))
print(loaded["theme"])

JSON supports objects, arrays, strings, numbers, booleans, and null. It does not directly store datetime, Decimal, sets, or arbitrary classes without conversion.

19.2 CSV

Python
import csv
from pathlib import Path

rows = [
    {"name": "Tea", "price": 4.5},
    {"name": "Coffee", "price": 5.0},
]

path = Path("products.csv")
with path.open("w", newline="", encoding="utf-8") as file:
    writer = csv.DictWriter(file, fieldnames=["name", "price"])
    writer.writeheader()
    writer.writerows(rows)

Read it safely:

Python
import csv
from pathlib import Path

with Path("products.csv").open(newline="", encoding="utf-8") as file:
    products = [
        {"name": row["name"], "price": float(row["price"])}
        for row in csv.DictReader(file)
    ]

CSV has no universal schema. Convert types and validate required columns explicitly.

20. Dates and times

20.1 date, time, and datetime

Python
from datetime import date, datetime, timedelta

today = date.today()
deadline = today + timedelta(days=14)
now = datetime.now()

print(deadline)

21.1 A simple class

class BankAccount:

        self.owner = owner

21.3 Properties protect rules

class Temperature:
    def __init__(self, celsius: float) -> None:
        self.celsius = celsius

    @property
    def celsius(self) -> float:
        return self._celsius

    @celsius.setter
    def celsius(self, value: float) -> None:
        if value < -273.15:
            raise ValueError("temperature is below absolute zero")
        self._celsius = float(value)

22. Type hints and readable interfaces

22.1 Annotate function contracts

Python
def summarize(values: list[float]) -> dict[str, float]:
    if not values:
        raise ValueError("values cannot be empty")
    return {
        "minimum": min(values),
        "maximum": max(values),
        "average": sum(values) / len(values),
    }

Python does not enforce annotations automatically. Editors, linters, and type checkers use them to catch mistakes and explain interfaces.

22.2 Optional values and aliases

Python
from typing import TypeAlias

UserId: TypeAlias = int

def find_name(user_id: UserId) -> str | None:
    users = {1: "Ada", 2: "Grace"}
    return users.get(user_id)

22.3 Duck typing

Python often cares about supported behavior rather than exact class identity. If an object provides the expected methods, it can participate. Type protocols can document this without inheritance.

Python
from typing import Protocol

class Writer(Protocol):
    def write(self, text: str) -> object: ...

def save_message(destination: Writer, message: str) -> None:
    destination.write(message)

24.2 Data model and conversion

Python
from dataclasses import asdict, dataclass
from datetime import date

@dataclass(frozen=True)
class Expense:
    amount: float
    category: str
    occurred_on: date
    note: str = ""

    def __post_init__(self) -> None:
        if self.amount <= 0:
            raise ValueError("amount must be positive")
        if not self.category.strip():
            raise ValueError("category cannot be empty")

    def to_dict(self) -> dict[str, object]:
        data = asdict(self)
        data["occurred_on"] = self.occurred_on.isoformat()
        return data

    @classmethod
    def from_dict(cls, data: dict[str, object]) -> "Expense":
        return cls(
            amount=float(data["amount"]),
            category=str(data["category"]),
            occurred_on=date.fromisoformat(str(data["occurred_on"])),
            note=str(data.get("note", "")),
        )

24.3 Persistence

Python
import json
from pathlib import Path

def load_expenses(path: Path) -> list[Expense]:
    if not path.exists():
        return []
    raw = json.loads(path.read_text(encoding="utf-8"))
    if not isinstance(raw, list):
        raise ValueError("expense file must contain a list")
    return [Expense.from_dict(item) for item in raw]


def save_expenses(path: Path, expenses: list[Expense]) -> None:
    payload = [expense.to_dict() for expense in expenses]
    path.write_text(json.dumps(payload, indent=2), encoding="utf-8")

24.4 Summaries

Python
def totals_by_category(expenses: list[Expense]) -> dict[str, float]:
    totals: dict[str, float] = {}
    for expense in expenses:
        category = expense.category.strip().casefold()
        totals[category] = totals.get(category, 0.0) + expense.amount
    return totals


def overall_total(expenses: list[Expense]) -> float:
    return sum(expense.amount for expense in expenses)

24.5 Input helpers

Python
from datetime import date

def prompt_expense() -> Expense:
    amount = float(input("Amount: ").strip())
    category = input("Category: ").strip()
    raw_date = input("Date [YYYY-MM-DD, blank=today]: ").strip()
    occurred_on = date.fromisoformat(raw_date) if raw_date else date.today()
    note = input("Note: ").strip()
    return Expense(amount, category, occurred_on, note)

24.6 Command loop

Python
from pathlib import Path

DATA_PATH = Path("expenses.json")

def main() -> None:
    expenses = load_expenses(DATA_PATH)

    while True:
        command = input("[add/list/summary/quit] > ").strip().casefold()

        if command == "add":
            try:
                expenses.append(prompt_expense())
                save_expenses(DATA_PATH, expenses)
            except ValueError as exc:
                print(f"Invalid expense: {exc}")
        elif command == "list":
            for expense in expenses:
                print(
                    f"{expense.occurred_on} | {expense.category:<12} | "
                    f"${expense.amount:>8.2f} | {expense.note}"
                )
        elif command == "summary":
            for category, total in sorted(totals_by_category(expenses).items()):
                print(f"{category:<12} ${total:>8.2f}")
            print(f"{'overall':<12} ${overall_total(expenses):>8.2f}")
        elif command == "quit":
            break
        else:
            print("Unknown command")


if __name__ == "__main__":
    main()

26. Style, quality, and project habits

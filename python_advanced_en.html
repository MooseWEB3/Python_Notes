How to use this guide

Advanced Python is less about obscure syntax and more about understanding the contracts behind ordinary syntax. A for loop uses the iterator protocol, with uses the context-manager protocol, attribute access invokes descriptors, and await coordinates cooperative tasks. Once these mechanisms are clear, library code becomes easier to read and application design becomes more deliberate.

This guide assumes that you can already write functions, classes, comprehensions, exceptions, files, tests, and virtual environments. Examples target Python 3.11 or newer; a few notes describe newer improvements. Type annotations are written with modern built-in generic syntax.

Learning goals

By the end, you will be able to:

  • reason about identity, mutability, hashing, copying, and Python's data model;
  • build lazy pipelines with iterators, generators, and itertools;
  • design decorators, context managers, descriptors, and callable objects;
  • express reusable interfaces with generics, protocols, ParamSpec, and overloads;
  • choose appropriately among threads, processes, and asyncio;
  • structure packages around explicit dependencies and stable boundaries;
  • write layered tests, diagnose failures, profile bottlenecks, and reduce risk;
  • build a concurrent, extensible log-analysis application.

1. Advanced Python mindset and environment

1.1 Prefer contracts over tricks

A powerful feature is useful only when it makes a contract clearer. A generator can expose a lazy stream, a protocol can decouple a service from storage, and a decorator can apply one cross-cutting policy. The same tools become harmful when they hide control flow or create implicit global state.

Use four questions before adopting an advanced technique:

  1. What behavior does the caller observe?
  2. Which failures are part of the interface?
  3. Who owns resources and mutable state?
  4. Is a simpler function or object sufficient?

2.1 A small sequence type

Python
from collections.abc import Iterator, Sequence
from typing import overload


class TemperatureSeries(Sequence[float]):
    def __init__(self, values: list[float]) -> None:
        self._values = tuple(float(value) for value in values)

    def __len__(self) -> int:
        return len(self._values)

    @overload
    def __getitem__(self, index: int) -> float: ...

    @overload
    def __getitem__(self, index: slice) -> "TemperatureSeries": ...

    def __getitem__(self, index: int | slice) -> float | "TemperatureSeries":
        result = self._values[index]
        if isinstance(index, slice):
            return TemperatureSeries(list(result))
        return result

    def __iter__(self) -> Iterator[float]:
        return iter(self._values)


series = TemperatureSeries([18, 21.5, 19])
print(len(series), series[1], list(series[:2]))

Inheriting Sequence documents the intended contract and supplies mixin methods such as index() and count(). Implement only protocols your type can honor consistently.

2.2 Reflected operations and NotImplemented

Python
from dataclasses import dataclass


@dataclass(frozen=True)
class Vector:
    x: float
    y: float

    def __add__(self, other: object) -> "Vector":
        if not isinstance(other, Vector):
            return NotImplemented
        return Vector(self.x + other.x, self.y + other.y)

    def __mul__(self, scalar: object) -> "Vector":
        if not isinstance(scalar, int | float):
            return NotImplemented
        return Vector(self.x * scalar, self.y * scalar)

    def __rmul__(self, scalar: object) -> "Vector":
        return self * scalar


print(Vector(1, 2) + Vector(3, 4))
print(3 * Vector(2, 5))

Return NotImplemented for an unsupported operand so Python can try the reflected method or raise the correct TypeError. Do not raise NotImplemented; it is a singleton value, not an exception.

2.3 Representation and formatting

Python
class ByteSize:
    def __init__(self, count: int) -> None:
        if count < 0:
            raise ValueError("count cannot be negative")
        self.count = count

    def __repr__(self) -> str:
        return f"ByteSize({self.count!r})"

    def __str__(self) -> str:
        return f"{self.count:,} bytes"

    def __format__(self, spec: str) -> str:
        if spec == "kb":
            return f"{self.count / 1024:.2f} KiB"
        return format(str(self), spec)


size = ByteSize(2_560)
print(repr(size))
print(str(size))
print(f"{size:kb}")

repr() should favor unambiguous developer information; str() should favor a readable user representation.

3. Identity, mutability, aliasing, and copying

Assignment binds a name to an object; it does not copy the object. Mutating a shared object is visible through every alias.

Python
configuration = {"features": ["search"]}
alias = configuration
alias["features"].append("export")

print(configuration)
print(alias is configuration)

3.1 Shallow and deep copies

Python
from copy import copy, deepcopy

original = {"name": "job", "steps": [{"action": "load"}]}
shallow = copy(original)
deep = deepcopy(original)

shallow["steps"][0]["action"] = "validate"
deep["steps"].append({"action": "save"})

print(original)
print(deep)

A shallow copy duplicates the outer container and shares nested objects. A deep copy recursively duplicates an object graph, but it can be expensive or semantically wrong for files, locks, database connections, and shared domain entities. Explicit reconstruction is often safer.

3.2 Immutable value objects

Python
from dataclasses import dataclass, replace
from decimal import Decimal


@dataclass(frozen=True, slots=True)
class Money:
    amount: Decimal
    currency: str

    def __post_init__(self) -> None:
        if len(self.currency) != 3:
            raise ValueError("currency must be a three-letter code")
        object.__setattr__(self, "currency", self.currency.upper())


price = Money(Decimal("19.99"), "cad")
discounted = replace(price, amount=Decimal("17.99"))
print(price, discounted)

Immutability makes sharing safer and simplifies hashing, caching, concurrency, and reasoning. It does not guarantee that referenced fields are deeply immutable.

3.3 Weak references

Weak references observe an object without keeping it alive, which is useful for caches and registries that must not control lifetime.

Python
import weakref


class Session:
    pass


session = Session()
reference = weakref.ref(session)
print(reference() is session)

del session
print(reference())

Do not use weak references as a substitute for clear ownership. They introduce timing-sensitive absence that callers must handle.

5.3 Memory views and binary data

memoryview can expose slices of binary buffers without copying the underlying bytes.

Python
payload = bytearray(b"HEADER:data")
view = memoryview(payload)
body = view[7:]
body[:4] = b"INFO"

This matters for large buffers and high-throughput I/O, but ordinary bytes operations are simpler unless profiling shows copies are significant.

6. Iterables, iterators, and lazy evaluation

An iterable can produce an iterator. An iterator remembers traversal state and returns one value per next() call until it raises StopIteration.

Python
values = [10, 20, 30]
iterator = iter(values)

print(next(iterator))
print(next(iterator))
print(list(iterator))
print(list(iterator))  # exhausted iterators stay exhausted

6.1 A custom iterator

Python
from collections.abc import Iterator


class Countdown(Iterator[int]):
    def __init__(self, start: int) -> None:
        self.current = start

    def __iter__(self) -> "Countdown":
        return self

    def __next__(self) -> int:
        if self.current <= 0:
            raise StopIteration
        value = self.current
        self.current -= 1
        return value


print(list(Countdown(3)))

Most custom iteration is shorter and clearer as a generator, but implementing the protocol once makes lazy behavior explicit.

6.2 Sentinel iteration

The two-argument form iter(callable, sentinel) repeatedly calls a zero-argument callable until the sentinel is returned.

Python
from io import StringIO

stream = StringIO("alpha\nbeta\n")
lines = iter(stream.readline, "")

for line in lines:
    print(line.rstrip())

6.3 Single-pass interfaces

If a function may accept an iterator, do not traverse it twice unless you explicitly materialize it.

Python
from collections.abc import Iterable


def summarize(values: Iterable[float]) -> tuple[int, float]:
    count = 0
    total = 0.0
    for value in values:
        count += 1
        total += value
    return count, total


print(summarize(number / 10 for number in range(5)))

7. Generators and coroutine-like generator features

A function containing yield returns a generator object. Its local state is suspended between values.

Python
from collections.abc import Iterator


def read_batches(items: list[str], size: int) -> Iterator[list[str]]:
    if size <= 0:
        raise ValueError("size must be positive")
    for start in range(0, len(items), size):
        yield items[start : start + size]


for batch in read_batches(["a", "b", "c", "d", "e"], 2):
    print(batch)

7.1 Delegation with yield from

Python
from collections.abc import Iterable, Iterator


def flatten(groups: Iterable[Iterable[int]]) -> Iterator[int]:
    for group in groups:
        yield from group


print(list(flatten([[1, 2], [], [3, 4]])))

yield from delegates iteration and also forwards advanced generator operations. For ordinary flattening, its most important benefit is expressing delegation clearly.

7.2 Cleanup and GeneratorExit

Python
from collections.abc import Iterator


def managed_stream() -> Iterator[int]:
    print("open")
    try:
        yield 1
        yield 2
    finally:
        print("close")


stream = managed_stream()
print(next(stream))
stream.close()

Consumers should close generators that own resources, or the generator should acquire the resource inside a context managed by the caller.

7.3 Sending values

Python
from collections.abc import Generator


def running_average() -> Generator[float, float, None]:
    total = 0.0
    count = 0
    value = yield 0.0
    while True:
        total += value
        count += 1
        value = yield total / count


averager = running_average()
next(averager)
print(averager.send(10))
print(averager.send(20))
averager.close()

Generator send() is educational but is rarely the clearest application architecture today. Use ordinary objects for stateful APIs and async coroutines for asynchronous workflows.

8.2 Sliding windows

Python
from collections import deque
from collections.abc import Iterable, Iterator
from itertools import islice
from typing import TypeVar

T = TypeVar("T")


def sliding_window(values: Iterable[T], size: int) -> Iterator[tuple[T, ...]]:
    if size <= 0:
        raise ValueError("size must be positive")
    iterator = iter(values)
    window = deque(islice(iterator, size), maxlen=size)
    if len(window) == size:
        yield tuple(window)
    for value in iterator:
        window.append(value)
        yield tuple(window)


print(list(sliding_window([1, 2, 3, 4], 3)))

8.3 Infinite iterators require boundaries

Python
from itertools import count, islice

even_numbers = (number for number in count() if number % 2 == 0)
print(list(islice(even_numbers, 5)))

Pair infinite sources such as count(), cycle(), and repeat() with islice(), a stopping predicate, or an external cancellation policy.

9.1 Closures capture bindings

10. Decorators that preserve contracts

A decorator receives a callable and returns a replacement callable. It is appropriate for one policy shared across many functions, such as tracing, caching, authorization, retry, or registration.

10.1 A typed timing decorator

Python
from collections.abc import Callable
from functools import wraps
from time import perf_counter
from typing import ParamSpec, TypeVar

P = ParamSpec("P")
R = TypeVar("R")


def timed(function: Callable[P, R]) -> Callable[P, R]:
    @wraps(function)
    def wrapper(*args: P.args, **kwargs: P.kwargs) -> R:
        started = perf_counter()
        try:
            return function(*args, **kwargs)
        finally:
            elapsed = perf_counter() - started
            print(f"{function.__name__} took {elapsed:.6f}s")

    return wrapper


@timed
def total(values: list[int]) -> int:
    return sum(values)


print(total([1, 2, 3]))

functools.wraps preserves metadata and the __wrapped__ chain, helping documentation, inspection, testing, and other decorators.

10.2 A parameterized retry decorator

Python
from collections.abc import Callable
from functools import wraps
from time import sleep
from typing import ParamSpec, TypeVar

P = ParamSpec("P")
R = TypeVar("R")


def retry(
    *,
    attempts: int,
    delay: float = 0.0,
    retry_on: tuple[type[Exception], ...] = (OSError,),
) -> Callable[[Callable[P, R]], Callable[P, R]]:
    if attempts < 1:
        raise ValueError("attempts must be at least one")

    def decorate(function: Callable[P, R]) -> Callable[P, R]:
        @wraps(function)
        def wrapper(*args: P.args, **kwargs: P.kwargs) -> R:
            last_error: Exception | None = None
            for attempt in range(1, attempts + 1):
                try:
                    return function(*args, **kwargs)
                except retry_on as error:
                    last_error = error
                    if attempt < attempts:
                        sleep(delay)
            assert last_error is not None
            raise last_error

        return wrapper

    return decorate

Retry only operations known to be safe to repeat. Use bounded attempts, classify transient failures precisely, add jitter in distributed systems, and preserve an overall time budget.

10.3 Class-based decorators

Python
from collections.abc import Callable
from dataclasses import dataclass, field
from typing import Any


@dataclass
class CountCalls:
    function: Callable[..., Any]
    calls: int = field(default=0, init=False)

    def __call__(self, *args: object, **kwargs: object) -> Any:
        self.calls += 1
        return self.function(*args, **kwargs)


@CountCalls
def greet(name: str) -> str:
    return f"Hello, {name}"


print(greet("Ada"))
print(greet.calls)

Class decorators store state naturally, but descriptor binding must be considered if they decorate instance methods. A function-based wrapper is usually simpler.

11. Context managers and deterministic cleanup

Context managers define setup and teardown around a block. Cleanup runs whether the block succeeds, returns, or raises.

Python
class Transaction:
    def __enter__(self) -> "Transaction":
        print("BEGIN")
        return self

    def commit(self) -> None:
        print("COMMIT")

    def rollback(self) -> None:
        print("ROLLBACK")

    def __exit__(
        self,
        exc_type: type[BaseException] | None,
        exc_value: BaseException | None,
        traceback: object,
    ) -> bool:
        if exc_type is None:
            self.commit()
        else:
            self.rollback()
        return False


with Transaction():
    print("update records")

Returning True from __exit__ suppresses the exception. Suppress only failures the context manager can fully handle; unexpected errors should propagate.

11.1 Generator-based context managers

Python
from collections.abc import Iterator
from contextlib import contextmanager
from pathlib import Path
from tempfile import TemporaryDirectory


@contextmanager
def temporary_workspace() -> Iterator[Path]:
    with TemporaryDirectory() as directory:
        path = Path(directory)
        print(f"created {path}")
        yield path
        print(f"removing {path}")


with temporary_workspace() as workspace:
    (workspace / "result.txt").write_text("done", encoding="utf-8")

Exactly one yield separates setup from teardown. Put teardown in finally if additional code before or after yield can fail.

11.2 Dynamic resources with ExitStack

Python
from contextlib import ExitStack
from pathlib import Path
from typing import TextIO

from typing import Any


class PositiveNumber:

14. Controlled metaprogramming

Metaprogramming changes classes or functions during definition. Prefer the least powerful tool that solves the problem: ordinary functions, class decorators, __init_subclass__, and only then metaclasses.

14.1 Registries with __init_subclass__

Python
from typing import ClassVar


class Parser:
    registry: ClassVar[dict[str, type["Parser"]]] = {}
    format_name: ClassVar[str]

    def __init_subclass__(cls, *, format_name: str, **kwargs: object) -> None:
        super().__init_subclass__(**kwargs)
        if format_name in cls.registry:
            raise ValueError(f"duplicate parser: {format_name}")
        cls.format_name = format_name
        cls.registry[format_name] = cls

    def parse(self, text: str) -> object:
        raise NotImplementedError


class TextParser(Parser, format_name="text"):
    def parse(self, text: str) -> object:
        return text.strip()


print(Parser.registry)

Automatic registration reduces wiring but creates import-order requirements: a plugin must be imported before it appears in the registry. Document that lifecycle explicitly.

18.1 Shared-state race

class Counter:

20. Processes and CPU parallelism

Processes have separate memory spaces. Arguments and results normally need to be serializable.

Python
from concurrent.futures import ProcessPoolExecutor


def count_primes(limit: int) -> int:
    def is_prime(value: int) -> bool:
        if value < 2:
            return False
        divisor = 2
        while divisor * divisor <= value:
            if value % divisor == 0:
                return False
            divisor += 1
        return True

    return sum(is_prime(value) for value in range(limit))


def main() -> None:
    limits = [20_000, 22_000, 24_000]
    with ProcessPoolExecutor() as executor:
        print(list(executor.map(count_primes, limits)))


if __name__ == "__main__":
    main()

The __main__ guard is essential on platforms that spawn fresh interpreters. Worker callables should be importable top-level functions, not local functions or lambdas.

20.1 Chunking and overhead

Tiny tasks may spend more time serializing and scheduling than computing. Group small units into chunks and benchmark the end-to-end path.

from collections.abc import Iterable

20.2 Process safety

Do not pass live sockets, database sessions, locks from another context, or open transactional state unless the library explicitly supports it. Initialize process-local resources inside each worker and close them there.

21.1 Structured concurrency with TaskGroup

        plugins.append(plugin())
    return plugins

Loading a plugin executes third-party code. Treat the installed environment as trusted, validate the plugin interface, isolate failures, and document version compatibility.

23.4 Public APIs

Keep internal modules private by convention and re-export a small stable surface from __init__.py. Semantic versioning is useful only when breaking behavior is defined and tested.

28. Capstone: concurrent extensible log analyzer

The capstone combines immutable domain records, streaming parsing, plugins, structured concurrency, bounded queues, tests, profiling, and a clean package boundary.

28.1 Requirements

  • stream newline-delimited JSON without loading the whole file;
  • validate timestamps, levels, services, and messages;
  • process several files concurrently with a bounded worker count;
  • aggregate counts and keep a limited sample of errors;
  • allow trusted analysis plugins;
  • expose a CLI and deterministic tests;
  • preserve useful context when individual lines are invalid.

28.2 Domain model and parser

Python
from dataclasses import dataclass
from datetime import datetime
import json


@dataclass(frozen=True, slots=True)
class LogEvent:
    timestamp: datetime
    level: str
    service: str
    message: str


class LogParseError(ValueError):
    pass


def parse_log_line(line: str) -> LogEvent:
    try:
        payload = json.loads(line)
        if not isinstance(payload, dict):
            raise TypeError("record must be an object")
        timestamp = datetime.fromisoformat(str(payload["timestamp"]))
        level = str(payload["level"]).upper()
        service = str(payload["service"]).strip()
        message = str(payload["message"]).strip()
    except (KeyError, TypeError, ValueError, json.JSONDecodeError) as error:
        raise LogParseError("invalid log record") from error

    if level not in {"DEBUG", "INFO", "WARNING", "ERROR", "CRITICAL"}:
        raise LogParseError(f"unsupported level: {level}")
    if not service or not message:
        raise LogParseError("service and message are required")
    return LogEvent(timestamp, level, service, message)

28.3 Streaming a file

Python
from collections.abc import Iterator
from pathlib import Path


def iter_events(path: Path) -> Iterator[LogEvent]:
    with path.open("r", encoding="utf-8") as handle:
        for line_number, line in enumerate(handle, start=1):
            if not line.strip():
                continue
            try:
                yield parse_log_line(line)
            except LogParseError as error:
                error.add_note(f"file={path} line={line_number}")
                raise

Depending on requirements, a production stream can yield a result type containing either an event or an error instead of stopping at the first invalid line.

28.4 Aggregation with bounded samples

Python
from collections import Counter, deque
from dataclasses import dataclass, field


@dataclass
class Summary:
    by_level: Counter[str] = field(default_factory=Counter)
    by_service: Counter[str] = field(default_factory=Counter)
    error_samples: deque[str] = field(
        default_factory=lambda: deque(maxlen=20)
    )

    def add(self, event: LogEvent) -> None:
        self.by_level[event.level] += 1
        self.by_service[event.service] += 1
        if event.level in {"ERROR", "CRITICAL"}:
            self.error_samples.append(event.message)

    def merge(self, other: "Summary") -> None:
        self.by_level.update(other.by_level)
        self.by_service.update(other.by_service)
        self.error_samples.extend(other.error_samples)


def summarize_file(path: Path) -> Summary:
    summary = Summary()
    for event in iter_events(path):
        summary.add(event)
    return summary

28.5 Concurrent file processing

File parsing is mostly I/O with moderate CPU work, so a bounded thread pool is a reasonable first implementation. Measure before switching to processes.

Python
from concurrent.futures import ThreadPoolExecutor, as_completed
from pathlib import Path


def analyze_files(paths: list[Path], workers: int = 4) -> Summary:
    if workers < 1:
        raise ValueError("workers must be positive")
    combined = Summary()
    failures: list[Exception] = []

    with ThreadPoolExecutor(max_workers=workers) as executor:
        future_to_path = {
            executor.submit(summarize_file, path): path for path in paths
        }
        for future in as_completed(future_to_path):
            path = future_to_path[future]
            try:
                combined.merge(future.result())
            except Exception as error:
                error.add_note(f"while analyzing {path}")
                failures.append(error)

    if failures:
        raise ExceptionGroup("one or more log files failed", failures)
    return combined

Only the coordinator mutates combined, so no lock is required. Workers build independent summaries.

28.6 Plugin boundary

Python
from typing import Protocol


class AnalysisPlugin(Protocol):
    name: str
    def analyze(self, event: LogEvent) -> None: ...
    def report(self) -> dict[str, object]: ...


def run_plugins(
    events: list[LogEvent],
    plugins: list[AnalysisPlugin],
) -> dict[str, dict[str, object]]:
    for event in events:
        for plugin in plugins:
            plugin.analyze(event)
    return {plugin.name: plugin.report() for plugin in plugins}

For very large streams, invoke plugins during streaming rather than materializing events. Decide whether one plugin failure stops the run or becomes an isolated report.

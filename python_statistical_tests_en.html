How to Use This Tutorial

This tutorial explains how to perform common statistical tests in Python. It is written for readers who understand variables, means, and standard deviations but are new to statistical inference. Examples mainly use SciPy, statsmodels, pandas, and NumPy.

Code blocks are displayed but are not executed while the HTML is generated. Copy them into Jupyter Notebook, VS Code, or a Python script to run them.

A statistical test is not a button that turns data into stars. Begin with the research question and study design, inspect data quality and assumptions, and then report estimates, confidence intervals, effect sizes, and p-values together.

Learning Goals

After completing this tutorial, you should be able to:

  • Select a test from the variable types and study design;
  • Explain null hypotheses, p-values, significance levels, and Type I/II errors;
  • Run t-tests, ANOVA, nonparametric tests, and categorical tests;
  • Test correlations and interpret simple regression models;
  • Calculate effect sizes and confidence intervals;
  • Correct for multiple testing and plan sample sizes with power analysis;
  • Report results accurately without overstating conclusions.

This guide is for education and general analysis. It does not replace a domain-specific statistical review. Medical, clinical, safety-critical, or major business decisions should have their design, missing-data assumptions, and models reviewed by a qualified statistician.

rng = np.random.default_rng(42)

2. Core Ideas Behind Statistical Tests

2.1 Null and Alternative Hypotheses

Most statistical tests begin with two competing statements:

  • Null hypothesis H0H_0: no difference, no association, or a parameter equals a specified value;
  • Alternative hypothesis H1H_1: a difference or association exists, or the parameter differs from that value.

For example, when comparing the mean scores of two independent classes:

  • H0:μA=μBH_0: μ_A = μ_B
  • H1:μA≠μBH_1: μ_A ≠ μ_B

2.2 The p-Value

A p-value is the probability of observing the current result, or something more extreme, assuming the null hypothesis and model assumptions are true.

A p-value is not:

  • The probability that the null hypothesis is true;
  • The probability that chance caused the result;
  • The size or importance of the effect;
  • The probability that the result will replicate.

If α was set to 0.05 in advance and p < 0.05, the result is commonly called statistically significant. Statistical significance does not guarantee practical importance.

2.3 Type I and Type II Errors

Decision H0H_0 is true H0H_0 is false
Reject H0H_0 Type I error (false positive) Correct detection
Do not reject H0H_0 Correct Type II error (false negative)
  • The significance level α controls the Type I error rate;
  • Power is 1 - β: the probability of detecting a real effect of the planned size.

2.4 One-Sided or Two-Sided?

Unless a directional hypothesis was justified before seeing the data, use a two-sided test:

stats.ttest_ind(group_a, group_b, equal_var=False, alternative="two-sided")

Do not change to a one-sided test after a two-sided result fails to reach significance.

2.5 Confidence Intervals and Effect Sizes

A confidence interval communicates uncertainty. An effect size communicates the magnitude of a difference or association. A useful conclusion normally contains:

estimate + 95% confidence interval + effect size + test statistic + p-value + sample size

Do two groups differ? Two independent groups Welch t-test Mann–Whitney U
Did the same subjects change? Two paired measurements Paired t-test Wilcoxon signed-rank
Do 3+ independent groups differ? Independent groups ANOVA / Welch ANOVA Kruskal–Wallis

Answer four questions first:

  1. Is the outcome numeric, ordinal, or categorical?
  2. How many groups or time points are present?
  3. Are observations independent, paired, or repeatedly measured?
  4. Are you comparing locations, proportions, distributions, associations, or model coefficients?

4. Example Data and General Cleaning

group_a = rng.normal(loc=72, scale=8, size=30)
group_b = rng.normal(loc=77, scale=9, size=32)

before = rng.normal(loc=68, scale=7, size=28)
after = before + rng.normal(loc=4, scale=5, size=28)

three_groups = pd.DataFrame({
    "group": np.repeat(["control", "method_a", "method_b"], [30, 31, 29]),
    "score": np.concatenate([
        rng.normal(70, 8, 30),
        rng.normal(75, 8, 31),
        rng.normal(79, 10, 29)
    ])
})

Clean real data before testing:

df = pd.read_csv("experiment.csv")

df["score"] = pd.to_numeric(df["score"], errors="coerce")
df["group"] = df["group"].astype("category")

analysis = df.dropna(subset=["score", "group"]).copy()

print(analysis.shape)
print(analysis.groupby("group", observed=True)["score"].describe())

Do not silently delete every incomplete row. Record missingness by variable, compare complete and incomplete cases, and explain whether the analysis uses complete cases, imputation, or another method.

5. Descriptive Statistics and Visualization

Describe the data before testing it:

summary = (
    three_groups
    .groupby("group", observed=True)["score"]
    .agg(["count", "mean", "std", "median", "min", "max"])
)
summary["sem"] = summary["std"] / np.sqrt(summary["count"])
print(summary)

View raw observations with a box or violin plot:

import seaborn as sns
import matplotlib.pyplot as plt

sns.boxplot(data=three_groups, x="group", y="score", showfliers=False)
sns.stripplot(data=three_groups, x="group", y="score", color="black", alpha=0.55)
plt.show()

Means and standard deviations alone can hide skewness, outliers, bimodality, and unequal group sizes.

6. Checking Assumptions

6.1 Independence Comes From the Design

Independence cannot be established with one simple function. If a participant contributes multiple rows, students share classrooms, or patients share hospitals, observations may be correlated. Use paired/repeated-measures methods, cluster-robust standard errors, or mixed models as appropriate.

6.2 Normality: Shapiro–Wilk

result = stats.shapiro(group_a)
print(f"W={result.statistic:.3f}, p={result.pvalue:.4f}")
  • p < α: evidence of incompatibility with normality;
  • p ≥ α: insufficient evidence to reject normality, not proof of normality.

For t-tests and ANOVA, group errors or model residuals matter more than the pooled outcome. Normality tests detect trivial deviations in large samples and have low power in small samples, so also inspect a Q–Q plot:

import statsmodels.api as sm
import matplotlib.pyplot as plt

sm.qqplot(group_a, line="45", fit=True)
plt.show()

6.3 Equal Variances: Levene’s Test

levene = stats.levene(group_a, group_b, center="median")
print(f"W={levene.statistic:.3f}, p={levene.pvalue:.4f}")

The median-centered version is more robust to nonnormal data and outliers. Bartlett’s test is more sensitive to departures from normality:

stats.bartlett(group_a, group_b)

For two independent means, Welch’s t-test is generally safer than testing variances first and conditionally choosing Student’s or Welch’s test.

6.4 Outliers

q1, q3 = np.quantile(group_a, [0.25, 0.75])
iqr = q3 - q1
flagged = group_a[(group_a < q1 - 1.5 * iqr) | (group_a > q3 + 1.5 * iqr)]

Never remove an observation merely because it hurts significance. Use prespecified rules to determine whether it is an entry error, measurement failure, or genuine extreme value. A sensitivity analysis can report results with and without defensibly flagged observations.

7. One-Sample Tests

7.1 One-Sample t-Test

Question: Does the population mean differ from a target of 70?

sample = rng.normal(73, 8, 35)
test = stats.ttest_1samp(sample, popmean=70, alternative="two-sided")

n = len(sample)
mean = np.mean(sample)
sem = stats.sem(sample)
ci = stats.t.interval(0.95, df=n - 1, loc=mean, scale=sem)

print(f"mean={mean:.2f}, 95% CI={ci}")
print(f"t({n-1})={test.statistic:.3f}, p={test.pvalue:.4f}")

Observations should be independent and the data approximately normal. With larger samples, the t-test is often robust to modest nonnormality.

7.2 One-Sample Wilcoxon Signed-Rank Test

test = stats.wilcoxon(sample - 70, alternative="two-sided", zero_method="wilcox")
print(test)

This tests whether the difference distribution is centered on zero and assumes the differences are approximately symmetric. If symmetry is implausible, consider a sign test or a suitable resampling method.

8. Two Independent Groups

8.1 Welch’s Independent t-Test

Welch’s test does not require equal variances and is a strong default for comparing two independent means:

test = stats.ttest_ind(
    group_a,
    group_b,
    equal_var=False,
    alternative="two-sided",
    nan_policy="omit"
)
print(f"t={test.statistic:.3f}, p={test.pvalue:.4f}")

Calculate the Welch–Satterthwaite degrees of freedom and a confidence interval for the mean difference:

def welch_mean_difference(a, b, confidence=0.95):
    a = np.asarray(a, dtype=float)
    b = np.asarray(b, dtype=float)
    a, b = a[~np.isnan(a)], b[~np.isnan(b)]

    diff = a.mean() - b.mean()
    va, vb = a.var(ddof=1), b.var(ddof=1)
    se2 = va / len(a) + vb / len(b)
    df = se2**2 / (
        (va / len(a))**2 / (len(a) - 1) +
        (vb / len(b))**2 / (len(b) - 1)
    )
    critical = stats.t.ppf(1 - (1 - confidence) / 2, df)
    ci = (diff - critical * np.sqrt(se2), diff + critical * np.sqrt(se2))
    return diff, df, ci

diff, df_welch, ci = welch_mean_difference(group_a, group_b)
print(diff, df_welch, ci)

8.2 Cohen’s d and Hedges’ g

def cohens_d_independent(a, b):
    a, b = np.asarray(a), np.asarray(b)
    pooled_sd = np.sqrt(
        ((len(a) - 1) * a.var(ddof=1) + (len(b) - 1) * b.var(ddof=1)) /
        (len(a) + len(b) - 2)
    )
    return (a.mean() - b.mean()) / pooled_sd

d = cohens_d_independent(group_a, group_b)
correction = 1 - 3 / (4 * (len(group_a) + len(group_b)) - 9)
g = d * correction
print(f"Cohen's d={d:.3f}, Hedges' g={g:.3f}")

Values of 0.2, 0.5, and 0.8 are sometimes called small, medium, and large, but domain knowledge should determine practical importance. Hedges’ g corrects small-sample bias.

8.3 Mann–Whitney U

test = stats.mannwhitneyu(
    group_a,
    group_b,
    alternative="two-sided",
    method="auto"
)
print(f"U={test.statistic:.1f}, p={test.pvalue:.4f}")

It detects systematic differences in ranks/distributions. It can be interpreted as a median comparison only under additional shape assumptions. It does not automatically solve dependence, severe measurement problems, or every outlier issue.

9. Paired Data

9.1 Paired t-Test

test = stats.ttest_rel(after, before, alternative="two-sided", nan_policy="omit")
differences = after - before

n = len(differences)
mean_diff = differences.mean()
ci = stats.t.interval(0.95, df=n - 1, loc=mean_diff, scale=stats.sem(differences))
dz = mean_diff / differences.std(ddof=1)

print(f"mean change={mean_diff:.2f}, 95% CI={ci}")
print(f"t({n-1})={test.statistic:.3f}, p={test.pvalue:.4f}, dz={dz:.3f}")

The paired test concerns the mean and normality of within-subject differences, not the separate normality of the before and after measurements.

9.2 Paired Wilcoxon Signed-Rank Test

test = stats.wilcoxon(after, before, alternative="two-sided", zero_method="wilcox")
print(f"W={test.statistic:.1f}, p={test.pvalue:.4f}")

Pairs must remain correctly aligned. Do not independently delete missing before and after values and then assume the remaining row numbers still represent pairs.

10. Three or More Independent Groups

10.1 One-Way ANOVA

groups = [
    values["score"].to_numpy()
    for _, values in three_groups.groupby("group", observed=True)
]

test = stats.f_oneway(*groups)
print(f"F={test.statistic:.3f}, p={test.pvalue:.4f}")

Classical ANOVA assumes independent observations, approximately normal within-group errors, and similar variances. A significant omnibus test says at least one group differs; it does not identify which groups differ.

10.2 Welch ANOVA

Use Welch ANOVA when variances or sample sizes differ substantially:

welch = anova_oneway(groups, use_var="unequal", welch_correction=True)
print(welch)

10.3 Formula Interface and Eta Squared

from statsmodels.stats.anova import anova_lm

model = smf.ols("score ~ C(group)", data=three_groups).fit()
table = anova_lm(model, typ=2)

ss_group = table.loc["C(group)", "sum_sq"]
ss_resid = table.loc["Residual", "sum_sq"]
eta_squared = ss_group / (ss_group + ss_resid)

print(table)
print(f"eta squared={eta_squared:.3f}")

10.4 Tukey HSD Post-Hoc Comparisons

from statsmodels.stats.multicomp import pairwise_tukeyhsd

tukey = pairwise_tukeyhsd(
    endog=three_groups["score"],
    groups=three_groups["group"],
    alpha=0.05
)
print(tukey)

Tukey HSD is appropriate for all-pair comparisons after classical ANOVA. Games–Howell is better aligned with Welch ANOVA; the optional pingouin package provides it:

# python -m pip install pingouin
import pingouin as pg
pg.pairwise_gameshowell(data=three_groups, dv="score", between="group")

10.5 Kruskal–Wallis

test = stats.kruskal(*groups, nan_policy="omit")
print(f"H={test.statistic:.3f}, p={test.pvalue:.4f}")

A significant result still requires corrected pairwise comparisons, such as Dunn’s test or pairwise Mann–Whitney tests with Holm correction.

11. Three or More Repeated Measurements

11.1 Repeated-Measures ANOVA

from statsmodels.stats.anova import AnovaRM

n_subjects = 24
wide = pd.DataFrame({
    "subject": np.arange(n_subjects),
    "week_0": rng.normal(65, 7, n_subjects),
})
wide["week_4"] = wide["week_0"] + rng.normal(3, 4, n_subjects)
wide["week_8"] = wide["week_0"] + rng.normal(6, 5, n_subjects)

long = wide.melt(id_vars="subject", var_name="time", value_name="score")
result = AnovaRM(long, depvar="score", subject="subject", within=["time"]).fit()
print(result)

Repeated-measures ANOVA also involves sphericity. statsmodels.AnovaRM is relatively basic; mixed-effects models are usually preferable for complex missingness, multiple levels, or unbalanced data.

11.2 Friedman Test

test = stats.friedmanchisquare(wide["week_0"], wide["week_4"], wide["week_8"])
print(f"chi2={test.statistic:.3f}, p={test.pvalue:.4f}")

If the omnibus result is significant, perform pairwise Wilcoxon tests with a correction such as Holm.

12. Categorical Variables and Proportions

12.1 Chi-Square Test of Independence

table = pd.DataFrame(
    [[42, 18], [30, 30]],
    index=["treatment", "control"],
    columns=["success", "failure"]
)

chi2, p, dof, expected = stats.chi2_contingency(table, correction=False)
print(f"chi2({dof})={chi2:.3f}, p={p:.4f}")
print(pd.DataFrame(expected, index=table.index, columns=table.columns))

Use counts, not percentages. When expected counts are too small, the chi-square approximation may be unreliable; consider Fisher’s exact test for a 2×2 table.

12.2 Cramér’s V

n = table.to_numpy().sum()
r, c = table.shape
cramers_v = np.sqrt(chi2 / (n * min(r - 1, c - 1)))
print(f"Cramer's V={cramers_v:.3f}")

12.3 Fisher’s Exact Test

small_table = np.array([[8, 2], [1, 5]])
odds_ratio, p = stats.fisher_exact(small_table, alternative="two-sided")
print(f"odds ratio={odds_ratio:.3f}, p={p:.4f}")

Fisher’s exact test is common for small 2×2 tables. An odds ratio above 1 means the first row has higher event odds than the second, given the specified row and column order.

12.4 Two-Proportion z-Test

successes = np.array([120, 105])
totals = np.array([1000, 980])

z, p = proportions_ztest(successes, totals, alternative="two-sided")
rates = successes / totals
print(f"rates={rates}, z={z:.3f}, p={p:.4f}")

Also report a proportion difference, relative risk, or odds ratio with a confidence interval.

12.5 McNemar Test for Paired Categories

Use McNemar’s test for binary outcomes measured twice on the same subjects:

from statsmodels.stats.contingency_tables import mcnemar

paired_table = [[40, 12], [5, 43]]
result = mcnemar(paired_table, exact=True)
print(result.statistic, result.pvalue)

13. Correlation Tests

13.1 Pearson Correlation

x = rng.normal(50, 10, 80)
y = 12 + 0.7 * x + rng.normal(0, 7, 80)

result = stats.pearsonr(x, y)
print(f"r={result.statistic:.3f}, p={result.pvalue:.4f}")

Pearson measures linear association. Inspect a scatterplot, outliers, linearity, and heteroscedasticity. Correlation does not establish causation.

13.2 Spearman and Kendall

rho = stats.spearmanr(x, y, nan_policy="omit")
tau = stats.kendalltau(x, y, nan_policy="omit")

print(f"Spearman rho={rho.statistic:.3f}, p={rho.pvalue:.4f}")
print(f"Kendall tau={tau.statistic:.3f}, p={tau.pvalue:.4f}")
  • Spearman uses ranks and suits monotonic, possibly nonlinear relationships or ordinal data;
  • Kendall also uses ranks and can be attractive for small samples or many tied ranks.

Do not repeatedly try Pearson, Spearman, Kendall, and transformations and then report only the significant option.

14. Statistical Tests in Regression

14.1 Linear Regression

regression_df = pd.DataFrame({
    "score": y,
    "hours": x,
    "age": rng.integers(18, 55, len(x)),
    "group": rng.choice(["control", "treatment"], len(x))
})

model = smf.ols("score ~ hours + age + C(group)", data=regression_df).fit()
print(model.summary())

Each coefficient t-test asks whether that coefficient is zero after controlling for other model terms. Check:

  • Linear functional form;
  • Independent residuals;
  • Approximately constant residual variance;
  • Influential and high-leverage points;
  • Multicollinearity;
  • Approximately normal residuals when small-sample inference requires it.

Use heteroscedasticity-robust standard errors when appropriate:

robust = model.get_robustcov_results(cov_type="HC3")
print(robust.summary())

14.2 Logistic Regression

logit_df = pd.DataFrame({
    "converted": rng.binomial(1, 0.35, 200),
    "age": rng.integers(18, 65, 200),
    "variant": rng.choice(["A", "B"], 200)
})

model = smf.logit("converted ~ age + C(variant)", data=logit_df).fit(disp=False)
odds_ratios = np.exp(model.params)
odds_ci = np.exp(model.conf_int())

print(model.summary())
print(pd.DataFrame({"OR": odds_ratios, "CI_low": odds_ci[0], "CI_high": odds_ci[1]}))

Exponentiated logistic coefficients are odds ratios. An odds ratio is not a probability ratio; the difference becomes substantial when an event is common.

15. Goodness-of-Fit and Distribution Tests

15.1 Chi-Square Goodness-of-Fit

Test whether category counts follow expected proportions:

observed = np.array([48, 32, 20])
expected_proportions = np.array([0.50, 0.30, 0.20])
expected = observed.sum() * expected_proportions

test = stats.chisquare(f_obs=observed, f_exp=expected)
print(f"chi2={test.statistic:.3f}, p={test.pvalue:.4f}")

15.2 Normal-Fit Test: Lilliefors

The ordinary Kolmogorov–Smirnov p-value is not valid when the normal mean and standard deviation are estimated from the same sample. Use the Lilliefors correction:

from statsmodels.stats.diagnostic import lilliefors

statistic, p = lilliefors(group_a, dist="norm")
print(statistic, p)

Distribution tests are sample-size sensitive. Combine them with a Q–Q plot and an assessment of how robust the planned model is to the observed deviations.

16. Permutation Tests and Bootstrap

16.1 Permutation Test for a Mean Difference

def mean_difference(a, b):
    return np.mean(a) - np.mean(b)

result = stats.permutation_test(
    data=(group_a, group_b),
    statistic=mean_difference,
    permutation_type="independent",
    vectorized=False,
    n_resamples=10_000,
    alternative="two-sided",
    random_state=rng
)

print(result.statistic, result.pvalue)

Permutation tests require labels to be exchangeable under the null. Paired, clustered, and time-series designs need design-appropriate permutations; do not shuffle every row indiscriminately.

16.2 Bootstrap Confidence Interval

result = stats.bootstrap(
    data=(group_a,),
    statistic=np.mean,
    confidence_level=0.95,
    n_resamples=10_000,
    method="BCa",
    random_state=rng
)

print(result.confidence_interval)

Bootstrap estimates uncertainty by sampling with replacement. The sample must represent the target population, and ordinary row-level bootstrap is not valid for clustered or serially dependent observations.

17. Multiple-Testing Corrections

Testing many hypotheses increases the chance of at least one false positive.

raw_pvalues = np.array([0.004, 0.018, 0.031, 0.070, 0.21])

reject, corrected, _, _ = multipletests(
    raw_pvalues,
    alpha=0.05,
    method="holm"
)

result = pd.DataFrame({
    "p_raw": raw_pvalues,
    "p_holm": corrected,
    "reject": reject
})
print(result)
Method Controls Character
Bonferroni Family-wise error rate Simple and conservative
Holm Family-wise error rate Usually preferable to plain Bonferroni
Benjamini–Hochberg (fdr_bh) False discovery rate Common in exploratory high-dimensional work

Define the family of related tests before inspecting results. Do not split families merely to preserve significance.

18. Power Analysis and Sample Size

Required sample size per group for an independent t-test:

analysis = TTestIndPower()

n_per_group = analysis.solve_power(
    effect_size=0.5,
    alpha=0.05,
    power=0.80,
    ratio=1.0,
    alternative="two-sided"
)

print(np.ceil(n_per_group))

Sample-size planning needs an expected effect size, α, target power, allocation ratio, and test type. Base the expected effect on the smallest practically important difference and a defensible standard deviation, not automatically on the conventional “medium effect” of 0.5.

After a study is complete, do not use the observed effect as the main input to a post-hoc power calculation. Report the effect estimate and confidence interval instead.

19. Complete Example: A/B Test

Goal: compare conversion for a new variant B with existing variant A and report the absolute difference, relative risk, odds ratio, and p-value.

ab = pd.DataFrame({
    "variant": ["A", "B"],
    "conversions": [420, 486],
    "visitors": [5000, 5100]
})

ab["rate"] = ab["conversions"] / ab["visitors"]

# Arrange the z-test in the B - A direction
z, p = proportions_ztest(
    count=ab.loc[[1, 0], "conversions"].to_numpy(),
    nobs=ab.loc[[1, 0], "visitors"].to_numpy(),
    alternative="two-sided"
)

p_a, p_b = ab.loc[0, "rate"], ab.loc[1, "rate"]
absolute_lift = p_b - p_a
relative_risk = p_b / p_a

# Rows are B/A; columns are conversion/non-conversion
table = np.array([
    [ab.loc[1, "conversions"], ab.loc[1, "visitors"] - ab.loc[1, "conversions"]],
    [ab.loc[0, "conversions"], ab.loc[0, "visitors"] - ab.loc[0, "conversions"]]
])
odds_ratio, fisher_p = stats.fisher_exact(table)

# Approximate unpooled 95% CI for the proportion difference
se = np.sqrt(p_a * (1 - p_a) / ab.loc[0, "visitors"] +
             p_b * (1 - p_b) / ab.loc[1, "visitors"])
diff_ci = (absolute_lift - 1.96 * se, absolute_lift + 1.96 * se)

print(ab)
print(f"absolute lift={absolute_lift:.4f}, 95% CI={diff_ci}")
print(f"relative risk={relative_risk:.3f}")
print(f"odds ratio={odds_ratio:.3f}")
print(f"z={z:.3f}, p={p:.4f}, Fisher p={fisher_p:.4f}")
